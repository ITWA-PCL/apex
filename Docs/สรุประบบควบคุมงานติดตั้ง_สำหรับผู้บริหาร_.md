# ระบบควบคุมงานติดตั้งประตู-หน้าต่าง
### สรุปการทำงานทุกส่วน สำหรับนำเสนอผู้บริหาร

> **ระบบนี้ทำอะไร (1 ประโยค)**
> ติดตามงานติดตั้งประตู-หน้าต่างทุกบาน ตั้งแต่ได้งานจนส่งมอบ ให้รู้ว่าแต่ละบานอยู่ขั้นไหน ใครรับผิดชอบ มีปัญหาอะไร และกำไรเป็นอย่างไร ในหน้าจอเดียว

**แนวคิดหลัก:** หน่วยที่ควบคุมคือ **"ช่องเปิด 1 บาน"** แต่ละบานมีรหัสประจำตัว ตำแหน่งติดตั้ง ทีมช่าง สถานะ รูปถ่าย และมูลค่าของตัวเอง

## 1. ภาพรวมระบบ: 10 เมนูหลัก

| หน้าจอ | ใครใช้ | ตอบคำถามอะไร |
|---|---|---|
| **ระบบเสนองาน** | ฝ่ายขาย / ประมาณราคา, ผู้บริหาร | มีโอกาสงานอะไรบ้าง ยื่นราคาไปกี่ครั้ง ต้องติดตามใคร ได้งานกี่ % · ได้งานแล้วเปิดเป็นโครงการ |
| **ภาพรวมทุกโครงการ** | ผู้บริหาร | โครงการไหนเสี่ยง กำไรเท่าไร มีเรื่องด่วนอะไร |
| **รายโครงการ** | ผู้จัดการโครงการ, วิศวกร, QC, โฟร์แมน | มีโครงการอะไรบ้าง (กรองตามสถานะ) · งานแต่ละบานถึงไหน ต้องทำอะไรต่อ |
| **ทีมช่าง** | ผู้จัดการโครงการ, บัญชี | แต่ละทีมทำได้เท่าไร ว่าจ้างด้วยสัญญาอะไร ค่าจ้างเท่าไร |
| **รายงานประจำวัน** | โฟร์แมน → ผจก.โครงการ | วันนี้หน้างานมีคนกี่คน ทำอะไรไป อากาศเป็นอย่างไร |
| **ปัญหาหน้างาน** | โฟร์แมน, ผจก.โครงการ | อะไรทำให้งานช้า ใครเป็นต้นเหตุ ใช้ขอขยายเวลาได้ไหม |
| **มุมบัญชี (POC)** | บัญชี, ผู้บริหาร | รับรู้รายได้เท่าไรตามความสำเร็จของงาน ค่าจ้างช่างเกิดขึ้นเท่าไร ในช่วงเวลาที่เลือก |
| **กระแสเงินสด** | บัญชี, การเงิน, ผู้บริหาร | รับเงินเข้าเท่าไร จ่ายออกเท่าไร ค้างรับ/ค้างจ่ายเท่าไร · วางบิลและบันทึกรับเงินจากลูกค้า |
| **ผู้ใช้งาน** | ผู้ดูแลระบบ | ใครเข้าระบบได้ บทบาทอะไร เห็นโครงการไหน ผูกกับทีมช่างใด |
| **แบบฟอร์ม** | ทุกคน | พิมพ์แบบฟอร์ม F-01 ถึง F-14 · เลือกรายการที่จะใส่ในฟอร์มเองได้ ไม่เลือกได้แบบฟอร์มเปล่า |

**หน้ารายโครงการ** แสดงการ์ดทุกโครงการ กรองได้ 3 สถานะ: **ก่อนดำเนินงาน · อยู่ระหว่างดำเนินการ · ดำเนินงานแล้วเสร็จ** ค้นหาได้ และมีปุ่ม **“เปิดโครงการใหม่”** ในหน้าเดียวกัน

> 💡 **ไอเดียภาพ:** 6 ไอคอนเรียงกัน แบ่ง 2 แถว: ภาพรวม · โครงการ · ทีมช่าง / รายงานประจำวัน · ปัญหาหน้างาน · แบบฟอร์ม

## 2. เส้นทางของ 1 โครงการ (ภาพใหญ่)

```
ได้งาน → ตั้งค่าโครงการ (7 ขั้น) → เตรียมงาน · หน้างาน · ตรวจงาน (S1–S8) → ส่งมอบ / วางบิล / เบิกค่าแรง
```

แบ่งเป็น 2 ช่วง:
1. **ช่วงตั้งค่า** ทำครั้งเดียวตอนเริ่มโครงการ เพื่อเตรียมข้อมูลให้พร้อม
2. **ช่วงปฏิบัติงาน** ติดตามทุกบานผ่าน 8 ขั้นตอน จนส่งมอบ

> 💡 **ไอเดียภาพ:** เส้นทางแนวนอน 2 ช่วง สีต่างกัน ช่วงแรกเป็น "เตรียมงาน" ช่วงหลังเป็น "หน้างาน"

## 3. ช่วงตั้งค่าโครงการ: 7 ขั้น

ระบบมี **แถบติดตามขั้นตอน** อยู่ด้านบนของทุกโครงการ ขั้นที่เสร็จแล้วมีเครื่องหมาย ✓ ขั้นที่ต้องทำต่อจะเด่นขึ้นมา กดที่ขั้นไหนก็ไปหน้าที่ต้องทำได้ทันที

| ขั้น | ทำอะไร | ผลลัพธ์ |
|---|---|---|
| **1. เปิดโครงการ** | ใส่รหัสโครงการ ชื่อ **รหัสลูกค้าตามระบบ SAP** และ **แนบ Quotation ที่ลูกค้าลงนาม** (ได้หลายใบ) | โครงการมีตัวตนและมีหลักฐานการว่าจ้าง |
| **2. ระยะเวลา มูลค่า และงบ** | วันเริ่ม-สิ้นสุด (ขยายเวลาได้พร้อมแนบหนังสือ) · มูลค่าตามสัญญา 4 วิธี · งบประมาณ 3 หมวด · งานเพิ่ม | รู้กรอบเวลาและกรอบเงิน |
| **3–4. นำเข้า SO และรายได้** | นำไฟล์ Sale Order จาก SAP เข้าระบบ (1 โครงการมีได้หลาย SO) | ได้ **รายได้โครงการ** อัตโนมัติ |
| **5. ระบุตำแหน่งติดตั้ง** | กำหนดผังอาคาร ชั้น ห้อง แล้วระบุว่าแต่ละบานติดที่ไหน | **ทุกบานมีที่อยู่กำกับ** |
| **6. ทีมและการมอบหมาย** | กำหนด **ทีมช่างของโครงการในภาพรวม** ก่อน แล้วมอบงานรายชั้นหรือรายบาน โดยตัวเลือกแสดงเฉพาะทีมของโครงการ | ทุกบานมีเจ้าของงาน |
| **7. ค่าจ้างผู้รับเหมา** | ตั้งค่าจ้างต่อตารางเมตร หรือใส่แยกรายบาน | รู้ต้นทุนค่าแรงล่วงหน้า |

> 💡 **ไอเดียภาพ:** บันได 7 ขั้น หรือ checklist 7 ช่อง แต่ละขั้นมีไอคอน (ป้ายชื่อ, ปฏิทิน, เอกสาร, หมุดแผนที่, คน, เงิน)

### รายละเอียดที่ควรเน้นในแต่ละขั้น

**Quotation ที่ลูกค้าลงนาม**
- 1 โครงการแนบได้หลายใบ ใส่เลขที่ QT วันที่ ผู้ลงนาม และไฟล์ที่ลงนามแล้ว · **ไม่มี QT ลงนาม ขั้น “เปิดโครงการ” ไม่ครบ**

**การขยายระยะเวลาดำเนินการ**
- บันทึกได้หลายครั้ง (EOT-01, 02, …) ต้องแนบ **หนังสือขอขยายระยะเวลา** · สถานะ: ยื่นขอแล้ว / อนุมัติแล้ว / ไม่อนุมัติ
- วันสิ้นสุดโครงการเปลี่ยนเมื่อ “อนุมัติแล้ว” เท่านั้น ทุกหน้าจะคำนวณ “เหลือกี่วัน / เลยกำหนด” จากวันใหม่
- ระบบดึง **ปัญหาหน้างานที่กระทบเวลา** มาช่วยเขียนเหตุผล และร่างหนังสือขอขยายเวลา (F-12) ให้

**มูลค่าโครงการตามสัญญา: 4 วิธี** (ช่องกรอกเปลี่ยนตามวิธีที่เลือก)
| วิธี | ช่องที่กรอก |
|---|---|
| 3.1 งานรับเหมาติดตั้ง (ค่าสินค้า+ค่าติดตั้ง รวม) คิดค่าขนส่ง | ค่าสินค้าพร้อมติดตั้ง · ค่าขนส่ง |
| 3.2 แยกขายสินค้า ค่าติดตั้ง และค่าขนส่ง | ค่าสินค้า · ค่าติดตั้ง · ค่าขนส่ง |
| 3.3 ซื้อสินค้า ฟรีค่าติดตั้ง คิดค่าขนส่ง | ค่าสินค้า · ค่าขนส่ง (ค่าติดตั้ง = ฟรี) |
| 3.4 ซื้อสินค้า ฟรีค่าติดตั้งและค่าขนส่ง | ค่าสินค้าอย่างเดียว |
- กรอกค่าสินค้า/ค่าติดตั้งแบบรวมหรือไม่รวม VAT ก็ได้ ระบบแสดงทั้ง 2 แบบ พร้อม VAT 7% · **ค่าขนส่งไม่มี VAT** ระบบไม่คิด VAT กับค่าขนส่งทั้งในมูลค่าโครงการและรายการ SO · ปุ่มสลับ **“ไม่รวม VAT | รวม VAT”** ใช้ได้ทุกหน้า
- งบ ต้นทุน และกำไรขั้นต้น คิดแบบไม่รวม VAT เสมอ · ระบบบอก “SO นำเข้าแล้ว X% ของมูลค่าโครงการ”

**งานเพิ่ม (Variation order)**
- บันทึกงานเพิ่ม (VO-01, 02, …) พร้อม QT อ้างอิง มูลค่า งบต้นทุนเพิ่ม และเอกสารที่ลูกค้าลงนาม
- งานเพิ่มที่ “อนุมัติแล้ว” บวกเข้ามูลค่าโครงการและงบประมาณให้อัตโนมัติ

**ขั้น 3–4 · SO และรายได้**
- นำเข้าไฟล์ Excel จาก SAP ได้ทันที ระบบอ่านหัวคอลัมน์และจับคู่ให้เอง
- ระบบ **ตรวจรหัสลูกค้า** ในไฟล์ SO เทียบกับโครงการ ถ้าไม่ตรงจะเตือนสีแดง กันการนำเข้าผิดโครงการ
- ระบบ **แยกหมวดรายการให้อัตโนมัติ** เป็น 5 หมวด:
  - สินค้า (บาน)
  - สินค้า + ติดตั้ง
  - ค่าแรงติดตั้ง
  - ค่าขนส่ง
  - สินค้าอื่น / อุปกรณ์ (เช่น มุ้งลวด)
- รองรับทุกรูปแบบการเปิด SO ของบริษัท: SO รวมของ+ค่าแรง, SO แยกของกับค่าแรง, และ SO ค่าขนส่งเพิ่มเติม
- นำเข้าไฟล์เดิมซ้ำได้ ระบบอัปเดตรายการเดิม ไม่สร้างซ้ำ
- **แก้ไขทุกรายการได้** กรณีคีย์ผิด (จำนวน ราคา ขนาด รายละเอียด) · ระบบกันไม่ให้ลดจำนวนต่ำกว่าบานที่วางตำแหน่งแล้ว
- **Item รันอัตโนมัติ** 1, 2, 3 … ต่อใบ SO · มีช่อง **รหัสสินค้า/บริการ** และ **ชื่อตามแบบ** (เช่น W1, D2) ซึ่งตามไปแสดงในทุกบาน

**ขั้น 5 · ระบุตำแหน่งติดตั้ง**
- สร้างผังอาคารได้ในไม่กี่คลิก: ใส่ช่วงชั้นและจำนวนห้อง ระบบตั้งเลขห้องให้ (เช่น 301, 302) แก้เป็นชื่อห้องได้ (ห้องนอน, ห้องครัว)
- เลือกห้องจากตาราง "ชั้น × ห้อง" แล้วกดวาง รายการ SO ที่มี 8 บานจะกลายเป็น 8 ช่องเปิด แต่ละช่องมีอาคาร ชั้น ห้อง ขนาด และมูลค่าครบ
- **วางเกินจำนวนใน SO ไม่ได้** และมีตัวนับบานที่ยังไม่ได้ระบุตำแหน่ง

**ขั้น 7 · ค่าจ้างผู้รับเหมา**
- **แบบต่อตารางเมตร:** ใส่อัตรา เช่น 480 บาท/ตร.ม. ระบบคำนวณจากขนาดบานให้ทุกบาน ตั้งพื้นที่ขั้นต่ำได้ (บานเล็กคิดอย่างน้อย 1 ตร.ม.)
- **แบบใส่รายบาน:** บานพิเศษ เช่น บานสูงต้องใช้นั่งร้าน ใส่ค่าจ้างเฉพาะบานได้
- รู้ **ค่าจ้างทั้งสัญญาของแต่ละทีม** ก่อนเริ่มงาน

## 4. ช่วงปฏิบัติงาน: 8 ขั้นตอนต่อบาน (S1–S8)

| ขั้น | ชื่อ | ทำระดับ | จุดหยุดตรวจ ◆ | หลักฐาน |
|---|---|---|---|---|
| S1 | ทบทวนสัญญาและแบบ | **ทั้งโครงการ ครั้งเดียว** | | เช็กลิสต์ 6 ข้อ |
| S2 | สำรวจหน้างาน | ทีละช่อง | ◆ | **รูปถ่ายหน้างาน + กดยืนยัน** (F-01) |
| S3 | อนุมัติแบบผลิต | **ทีละแบบ** (1 แบบครอบคลุมหลายบาน) | ◆ | **ไฟล์ Shop drawing ที่ลูกค้าลงนามแล้ว** |
| S4 | รับของหน้างาน | ทีละช่อง | | **สแกน QR หรือคีย์รหัส QR** (F-03) |
| S5 | ติดตั้ง | ทีละช่อง | | **รูปทุกจุด + ตรวจรับรายจุดตาม %** (F-04) |
| S6 | ตรวจรับงานติดตั้ง (QC) | ทีละช่อง | ◆ | ฟังก์ชัน · ความสะอาด · ทดสอบน้ำ (F-05, F-06) |
| S7 | ส่งมอบงาน | **เป็นชุด** (รายชั้น/พื้นที่) | ◆ | **ต้องแนบหนังสือส่งมอบ F-07 ที่ลูกค้าลงนามก่อนบันทึก** · มีหน้าของตัวเอง |
| S8 | ปิดงาน | ทีละช่อง + ปิดทั้งโครงการ | | ไม่มี NCR · ส่งใบแจ้งหนี้ลูกค้าแล้ว · เอกสารท้ายโครงการ (F-08) · มีหน้าของตัวเอง |

**เปลี่ยนจากเดิม 10 ขั้น:** ตัด "ผลิต + QC โรงงาน" และ "ตรวจช่องเปิดก่อนติดตั้ง" ออก · ส่งของ-ตรวจรับ เปลี่ยนเป็นการสแกนรับที่หน้างาน

**กฎหลัก:** ขั้นที่เป็น **จุดหยุดตรวจ ◆** ต้องมีหลักฐานและผู้ลงนามก่อน ระบบจึงยอมให้ไปขั้นถัดไป

> 💡 **ไอเดียภาพ:** เส้นทาง 8 สถานี สถานีที่มี ◆ เป็นรูปด่านตรวจหรือโล่ แบ่งสี 5 กลุ่มเหมือนในระบบ:
> เตรียมงาน (S1–S3) · รับของแล้ว (S4) · ติดตั้งแล้ว (S5) · ผ่าน QC (S6) · ส่งมอบแล้ว (S7–S8)

### S1 · ทบทวนสัญญาและแบบ (ทั้งโครงการ ครั้งเดียว)
- เช็กลิสต์ 6 ข้อ: สัญญาและขอบเขตงาน · แบบฉบับล่าสุด · สเปกวัสดุ · ตารางช่องเปิดตรงกับ SO · แผนงาน · จุดที่ต้องใช้นั่งร้านหรือเครน
- ติ๊กครบแล้วกดยืนยัน **ครั้งเดียว ทุกบานผ่าน S1 พร้อมกัน** ไม่ต้องกดทีละบาน

### S2 · สำรวจหน้างาน (ถ่ายรูป + ยืนยันทีละช่อง)
- ผู้สำรวจ **ถ่ายรูปช่องเปิดจากมือถือ แล้วกด "ยืนยันช่องเปิด"** ทีละช่อง
- ไม่มีรูป ยืนยันไม่ได้ · ต้องใส่ชื่อผู้ยืนยัน (ลงนาม F-01) ระบบจำชื่อไว้ให้
- **ใช้รูปร่วมตามชื่อตามแบบ:** หลังเพิ่มรูป ถ้ามีตำแหน่งอื่นที่ชื่อตามแบบเดียวกัน ระบบจะถามว่าจะแสดงรูปนี้ในช่องไหนบ้าง (เลือกทั้งหมด เลือกบางช่อง หรือใช้เฉพาะช่องนี้) · **การยืนยันช่องเปิดยังต้องกดทีละบานเสมอ**

### S3 · อนุมัติแบบผลิต (ทีละแบบ)
- ระบบสร้างรายการแบบจาก SO ให้อัตโนมัติ (1 แบบต่อ 1 รายการสินค้า) หรือ **รวมหลายรายการเป็นแบบเดียว** ก็ได้
- แต่ละแบบต้อง **แนบไฟล์ Shop drawing ที่ลูกค้าลงนามแล้ว** (PDF หรือรูปถ่าย) + ชื่อผู้ลงนามฝั่งลูกค้า + วันที่ + Rev
- **ไม่มีไฟล์ลงนาม อนุมัติไม่ได้** · กดอนุมัติครั้งเดียว ทุกบานในแบบผ่าน S3 พร้อมกัน
- บานที่สำรวจทีหลังจะผ่าน S3 อัตโนมัติเมื่อยืนยัน S2 · เปิดดูไฟล์แบบได้จากหน้ารายละเอียดของทุกบาน

### S4 · รับของหน้างาน
- โรงงาน **พิมพ์ป้าย QR ติดบาน** จากระบบ (1 บาน 1 ป้าย มีรหัส ตำแหน่ง และขนาด)
- เลือกได้เฉพาะ **ทีมที่ได้รับมอบหมายหรือมีสัญญาว่าจ้างในโครงการนั้น**
- รับของได้ **2 วิธีเท่านั้น:** 1) สแกน QR code ด้วยกล้อง 2) คีย์รหัสตามที่พิมพ์ใต้ QR code
- ระบบตรวจทันที: **ผิดโครงการ · แบบยังไม่อนุมัติ · รับซ้ำ · ทีมไม่ได้รับมอบหมาย** จะขึ้นเตือนและไม่ยอมรับ
- ของเสียหายกด **“แจ้งเสียหาย”** เปิด NCR สาเหตุ “ขนส่งเสียหาย” ได้ทันที

### S5 · ติดตั้ง (ถ่ายรูปทุกจุด + ตรวจรับรายจุด)
- เลือกได้ต่อโครงการ:
  - **จุดเดียว 100%:** ถ่ายรูปเมื่อติดตั้งเสร็จ กดยืนยัน แล้วส่งต่อ S6 ทันที
  - **กำหนดหลายจุด:** ตั้งชื่อจุดและ **% ของแต่ละจุดเอง รวมกันต้องเท่ากับ 100%** (เช่น เฟรม 40% · บาน 40% · sealant 20% หรือเพิ่มจุดอื่นได้ถึง 8 จุด)
- **เมื่อเริ่มทำงานแล้ว เปลี่ยนการตั้งค่านี้ไม่ได้**
- แบบหลายจุด: ช่างถ่ายรูปแล้ว **ส่งตรวจ** → ผู้ตรวจ **ตรวจรับจุดนั้น** (ผ่าน / ไม่ผ่านพร้อมเหตุผล) → จึงทำจุดถัดไปได้
  - การตรวจรับจุดย่อย **ไม่ตรวจ** ฟังก์ชันการใช้งาน ความสะอาด และทดสอบน้ำ
  - ไม่ผ่าน = ช่างแก้และถ่ายรูปส่งตรวจใหม่ ระบบเก็บประวัติไว้
- ทุกบานแสดง **% ความคืบหน้า** · แบบหลายจุด เมื่อผ่านครบทุกจุดต้อง **ตรวจรับงานติดตั้ง (final)** อีกครั้ง จึงส่งต่อ **S6 ตรวจรับงานติดตั้ง (QC)**

### S6–S7 · ตรวจคุณภาพ ส่งมอบ
- **S6 ตรวจรับงานติดตั้ง (QC) — มีหน้าของตัวเอง:** การ์ดทุกบานที่รอตรวจ ตรวจ **ฟังก์ชันการใช้งาน · ความสะอาด · ทดสอบน้ำ** (สุ่ม) ต้องผ่านทั้งฟังก์ชันและความสะอาด น้ำไม่รั่ว และไม่มี NCR ระดับ A/B ค้าง · **ข้อใดไม่ผ่าน ระบบบังคับเปิด NCR** ถ้ายกเลิก จะไม่บันทึกผลไม่ผ่าน
- **S7** ส่งมอบไม่ได้ถ้ายังมี NCR ค้างอยู่แม้แต่รายการเดียว

> 💡 **ไอเดียภาพ:** 3 ไอคอนเด่นของช่วงหน้างาน: เอกสารมีลายเซ็น (S3) · มือถือสแกน QR (S4) · กล้องถ่าย 3 ภาพ เฟรม/บาน/sealant (S5)

## 5. การจัดการปัญหา (NCR)

เมื่อพบข้อบกพร่อง เปิด NCR ผูกกับบานนั้นทันที

| ระดับ | ตัวอย่าง | กำหนดแก้ |
|---|---|---|
| 🔴 **A วิกฤต** | น้ำรั่ว กระจกแตก ผิดขนาดต้องผลิตใหม่ | 3 วัน |
| 🟠 **B สำคัญ** | บานฝืด ยาแนวไม่ต่อเนื่อง | 7 วัน |
| ⚪ **C เล็กน้อย** | รอยขีดข่วน คราบปูน | ก่อนส่งมอบ |

- ระบุสาเหตุ 5 กลุ่ม: วัดผิด · ผลิตผิด · ขนส่งเสียหาย · ติดตั้งผิด · ผู้อื่นทำเสียหาย (ใช้กำหนดว่าใครรับต้นทุน)
- QC ไม่ผ่านหรือทดสอบน้ำรั่ว → ระบบเปิดฟอร์ม NCR ให้ทันที
- NCR ที่เกินกำหนดจะขึ้นสีแดงในหน้าผู้บริหาร
- ปิด NCR ได้เมื่อ QC ตรวจซ้ำแล้วผ่าน

> 💡 **ไอเดียภาพ:** สัญญาณไฟจราจร 3 สี (A/B/C) + วงจร "พบ → ระบุสาเหตุ → แก้ไข → ตรวจซ้ำ → ปิด"

## 6. หน้าภาพรวมสำหรับผู้บริหาร

**ตัวเลขการเงินรวมทุกโครงการ**
- มูลค่างานรวม (สลับรวม/ไม่รวม VAT ได้) · กำไรขั้นต้นตามงบ · งบประมาณต้นทุนรวม · ต้นทุนจริงรวม
- **ต้นทุนจริงถึงวันนี้** = ค่าสินค้า + **ค่าจ้างช่างตามผลงานที่ตรวจรับแล้ว** (รวมงานเพิ่มที่ตรวจรับ และค่าแรงรายวันอื่น ๆ) + ค่าใช้จ่ายอื่น · ไม่ต้องรอจ่ายเงินจริง จึงเห็นต้นทุนตรงกับความคืบหน้างาน (ยอดจ่ายแล้วแสดงแยกไว้)
- **ค่าสินค้า เลือกแหล่งข้อมูลได้:** ดึงรายการสินค้าจาก SO (ตั้งต้นทุนเป็น % ของราคาขาย หรือกำหนดรายบรรทัด รับรู้ต้นทุนเมื่อรับของที่หน้างาน S4) หรือบันทึกเอง / นำเข้า Excel แบบเดิม

**ตัวเลขงานรวมทุกโครงการ**
- จำนวนโครงการและช่องเปิด · % ผ่าน QC · % ส่งมอบ · % ผ่าน QC ครั้งแรก · NCR ระดับ A · NCR เกินกำหนด · ช่องที่ยังไม่มอบทีม

**ตารางโครงการ** เรียงตามความเสี่ยง (NCR เกินกำหนด → โครงการเลยกำหนดหรือช้ากว่าแผน → NCR ระดับ A) แต่ละโครงการแสดง:
- ลูกค้า (รหัส SAP) และระยะเวลา
- สถานะเวลา: "เหลือ X วัน" / "ช้ากว่าแผน" / "เลยกำหนด X วัน" / "ส่งมอบครบแล้ว"
- แถบความคืบหน้า 5 สี
- มูลค่า · % ใช้งบ · % กำไรขั้นต้น
- NCR ที่เปิดอยู่ · ทีมช่างที่ทำงานอยู่
- ป้าย "ตั้งค่าโครงการ X/6" ถ้ายังตั้งค่าไม่ครบ

**รายการ "ต้องจัดการด่วน"** รวม NCR ระดับ A และ NCR เกินกำหนดจากทุกโครงการ กดแล้วไปที่บานนั้นทันที

> 💡 **ไอเดียภาพ:** หน้าปัดรถยนต์ (dashboard) ด้านบนเป็นตัวเลขสำคัญ ตรงกลางเป็นรายชื่อโครงการพร้อมไฟสถานะ ด้านล่างเป็นกล่องแจ้งเตือนสีแดง

## 7. การเงินของโครงการ

### รายได้ (มูลค่าโครงการ และ SO)
- มูลค่าโครงการตามสัญญา เทียบกับยอด SO ที่นำเข้าแล้ว (%)
- รายได้ตาม SO แยก 5 หมวด และสรุปรายใบ SO · ทุกตัวเลขสลับรวม/ไม่รวม VAT ได้
- **มูลค่างานส่งมอบแล้ว** ใช้ประกอบการวางบิล
  - สินค้า: คิดตามบานที่ส่งมอบจริง
  - ค่าแรง ค่าขนส่ง และอุปกรณ์: คิดตามสัดส่วนบานที่ส่งมอบแล้ว

### ต้นทุน 3 หมวด เทียบงบ
| หมวด | บันทึกอย่างไร |
|---|---|
| ค่าสินค้า | นำเข้าจาก Excel (PO History จาก SAP) หรือบันทึกทีละรายการ |
| ค่าแรงช่าง | เบิกตามงวดอัตโนมัติ + ค่าแรงอื่น เช่น รายวัน หรือค่าแก้งาน |
| ค่าใช้จ่ายอื่น | ค่าขนส่ง นั่งร้าน ที่พัก วัสดุสิ้นเปลือง ฯลฯ |

- แสดง งบ · ใช้จริง · คงเหลือ · % ใช้ไป ทุกหมวด
- **สัญญาณเตือน:** ถ้าใช้ค่าแรงเร็วกว่างานที่ผ่าน QC เกิน 10% ระบบเตือนก่อนงบเกิน

### การเบิกค่าแรงตามงวด
- เบิกตาม **งวดในสัญญาว่าจ้างของแต่ละทีม** (ถ้าไม่มีสัญญาใช้ค่าเริ่มต้น: 70% เมื่อผ่าน QC · 30% เมื่อส่งมอบและไม่มี NCR ค้าง)
- ระบบคำนวณยอดให้จากค่าจ้างรายบาน กดบันทึกครั้งเดียว
- **เบิกซ้ำไม่ได้** ระบบจำว่าบานไหนเบิกงวดไหนไปแล้ว
- ค่าแก้ไขงานจาก NCR สาเหตุ "ติดตั้งผิด" หักจากทีมได้

> 💡 **ไอเดียภาพ:** ตาชั่ง "รายได้ vs ต้นทุน" + แถบงบ 3 หมวด + เหรียญ 2 กอง (70% / 30%) วางบนเส้นทาง S6 และ S7

## 8. หน้าทีมช่าง · แยก “ทีมช่างภายใน” และ “ผู้รับเหมาภายนอก”

ด้านบนของหน้ามีปุ่มเลือก 2 ฝั่ง แต่ละฝั่งมีแท็บ ตัวเลขสรุป และข้อมูลของตัวเองแยกกันชัดเจน

**ทีมช่างภายใน (พนักงานบริษัท) · ค่าแรงรายชั่วโมง**

| แท็บ | มีอะไร |
|---|---|
| **ภาพรวมทีมภายใน** | ทีม/พนักงาน · บานที่มอบและติดตั้งแล้ว · ชั่วโมงทำงานเดือนนี้ (OT) · ค่าแรงเดือนนี้ · ผ่าน QC · NCR · ตารางผลงานเฉพาะทีมภายใน |
| **1 · ทะเบียนทีมและพนักงาน** | ทีม หัวหน้าทีม · **ตำแหน่งและค่าแรงต่อชั่วโมง** อัตรา OT ชั่วโมงปกติ/วัน · รายชื่อพนักงานพร้อมตำแหน่ง ค่าแรงเฉพาะคน สถานะ |
| **2 · มอบหมายเข้าโครงการ** | เลือกโครงการ–ทีม ช่วงเวลา ขอบเขต (ไม่ต้องทำ MOA) · ตารางต่อโครงการ: บานที่มอบ ติดตั้งแล้ว ชั่วโมงสะสม ค่าแรงสะสม **ค่าแรงต่อบานที่ติดตั้ง** |
| **3 · ชั่วโมงทำงานและค่าแรง** | บันทึกรายวัน: ติ๊กพนักงาน ชั่วโมงปกติ/OT → ค่าแรงตามตำแหน่ง · สรุปรายคน/รายโครงการ/รายทีม · CSV |

**ผู้รับเหมาภายนอก · ค่าจ้างตามผลงาน**

| แท็บ | มีอะไร |
|---|---|
| **ภาพรวมผู้รับเหมา** | จำนวนผู้รับเหมา · สัญญาใช้งานและมูลค่า · บานที่มอบ · ค่าจ้างตามผลงานค้างจ่าย · ใบเบิกรอดำเนินการ · NCR |
| **1 · ทะเบียนผู้รับเหมา** | ชื่อ หัวหน้าทีม เลขผู้เสียภาษี จด VAT ความชำนาญ |
| **2 · สัญญาว่าจ้าง (MOA)** | เลขที่ MOA + PDF · มูลค่า · หัก ณ ที่จ่าย · เงินประกันผลงาน · มัดจำ · หักเงินงวดตรวจรับ · ระยะประกันผลงาน · สัญญาเพิ่มเติม (F-14) · หนังสือรับรองเงินประกัน (F-17) |
| **3 · อัตราค่าจ้างติดตั้ง** | ต่อ ตร.ม. หรือต่อบาน · ค่าจ้างรวมจากการมอบงานรายบาน |
| **4 · ค่าจ้างตามผลงาน** | ทุกจุดส่งงานที่ตรวจรับแล้วตามช่วงเวลา · CSV |
| **5 · ส่งงาน / เบิกเงิน** | ใบส่งเบิกงานงวด (F-15) → อนุมัติ → ใบแจ้งหนี้ (F-16) → จ่ายเงิน · หักคืนมัดจำ/เงินงวดตรวจรับอัตโนมัติ |

**หลักความเป็นธรรม:** ผลงานคิดให้ทีมที่ติดตั้งจริงเสมอ · ต้นทุนค่าแรงทีมภายใน = ชั่วโมงจริง ส่วนผู้รับเหมา = ผลงานที่ตรวจรับแล้ว

## 8.1 รายงานประจำวัน (F-10)

- โฟร์แมนเขียนก่อนเลิกงาน 1 ฉบับต่อโครงการต่อวัน: เวลาทำงาน อากาศเช้า/บ่าย ชั่วโมงหยุดเพราะฝน
- **กำลังคนรายทีม** (จำนวนคน OT พื้นที่ทำงาน) เลือกได้เฉพาะทีมในโครงการ
- **ผลงานวันนี้นับให้อัตโนมัติจากระบบ:** สำรวจ รับของ ส่งตรวจจุดติดตั้ง ติดตั้งครบ ผ่าน QC ส่งมอบ เปิด/ปิด NCR
- งานที่ทำ วัสดุเข้า เครื่องมือ ความปลอดภัย ปัญหา แผนพรุ่งนี้ รูปหน้างาน
- ผจก.โครงการกด **“รับทราบ”** · ดูย้อนหลังและพิมพ์ F-10 ได้

## 8.2 ปัญหาหน้างาน (F-11)

- แยกจาก NCR ชัดเจน: **NCR = งานมีข้อบกพร่อง · ปัญหาหน้างาน = อุปสรรคที่ทำให้ทำงานไม่ได้หรือช้า**
- บันทึก: ประเภท (หน้างานไม่พร้อม ผู้รับเหมาหลักล่าช้า แบบเปลี่ยน ของไม่ครบ สภาพอากาศ ฯลฯ) ระดับ ตำแหน่ง จำนวนบานที่กระทบ **ผู้รับผิดชอบสาเหตุ** วันที่กระทบ ค่าใช้จ่าย เลขที่หนังสือแจ้ง การแก้ไข ผู้ติดตาม กำหนดเสร็จ รูปประกอบ
- ตัวเลขสรุป: ปัญหาค้าง · เกินกำหนด · **วันที่กระทบรวม** · **จำนวนที่ใช้ขอขยายเวลาได้** (สาเหตุจากภายนอกบริษัท)
- กดเดียวไปบันทึกขอขยายเวลา หรือพิมพ์ร่างหนังสือ F-12 ที่มีรายการปัญหาเป็นหลักฐาน

## 8.4 มุมบัญชี · รับรู้รายได้ตามขั้นความสำเร็จของงาน (Percentage-of-completion)

- เลือก **ช่วงเวลา** (เดือนนี้ · เดือนก่อน · ไตรมาสนี้ · ปีนี้ · ทั้งหมด · กำหนดเอง) และเลือกโครงการเดียวหรือทุกโครงการ
- เลือก **วิธีวัดความสำเร็จ:** ตามปริมาณงานติดตั้งที่ตรวจรับแล้ว (ถ่วงด้วยมูลค่าบาน) หรือ ตามต้นทุนจริงเทียบงบ
- แสดงต่อโครงการ: มูลค่าตามสัญญา · % สำเร็จต้นช่วง → สิ้นช่วง · **รายได้ที่รับรู้ในช่วง / สะสม / คงเหลือ** · **ปริมาณงานติดตั้งในช่วง** (บานครบ + เทียบเท่า) · **ค่าจ้างช่างที่เกิดขึ้น** เทียบค่าแรงที่จ่ายแล้ว และค่าจ้างค้างจ่าย
- ตารางแยก **รายเดือน / รายสัปดาห์** สำหรับดูแนวโน้ม · ตัวเลขไม่รวม VAT

> 💡 **ไอเดียภาพ:** กราฟแท่งรายเดือน “รายได้ที่รับรู้” คู่กับ “ค่าจ้างช่างที่เกิดขึ้น” + มาตรวัด % สำเร็จของแต่ละโครงการ

## 8.5 กระแสเงินสด (เฉพาะฝ่ายการเงิน)

เมนูใหม่ที่รวมเงินเข้า-ออกของทุกโครงการ (เลือกดูทุกโครงการหรือโครงการเดียว และเลือกช่วงเวลาได้) มี 4 แท็บ

| แท็บ | มีอะไร |
|---|---|
| **ภาพรวมกระแสเงินสด** | เงินรับ · เงินจ่าย (ค่าสินค้า ค่าแรงช่าง อื่น ๆ) · สุทธิ · ค้างรับจากลูกค้า (เกินกำหนด) · ค้างจ่ายผู้รับเหมา · กราฟรับ-จ่ายรายเดือน/รายสัปดาห์พร้อมยอดสะสม · **คาดการณ์ 90 วันข้างหน้า** |
| **รายการรับ-จ่าย** | ทุกรายการเรียงตามวันที่ พร้อมยอดคงเหลือสะสม · ดาวน์โหลด CSV |
| **วางบิล / รับเงิน (ลูกค้า)** | ย้ายมาจากหน้าโครงการ (รายละเอียดด้านล่าง) |
| **จ่ายเงินผู้รับเหมา** | ใบเบิกของผู้รับเหมาทุกใบ แยกสถานะ รอตรวจรับ / รอใบแจ้งหนี้ / รอจ่าย / จ่ายแล้ว |

**วางบิล / รับเงินจากลูกค้า**

- ออกใบแจ้งหนี้ลูกค้าตามงวด: เลือกฐาน (ตามบานที่ส่งมอบแล้ว · ตาม % ของสัญญา · กำหนดเอง)
- คำนวณให้: **VAT 7% เฉพาะค่าสินค้าและค่าติดตั้ง ค่าขนส่งไม่มี VAT** · หักเงินประกันผลงาน · หัก ณ ที่จ่าย · ยอดรับสุทธิ
- สถานะ: ร่าง → **กดส่งให้ลูกค้า** (อีเมล / ส่งเอกสาร / ระบบลูกค้า) → **บันทึกรับเงิน** ได้หลายครั้ง (รับบางส่วน / รับครบ) · ยกเลิกได้
- ตัวเลขสรุป: วางบิลแล้ว · รับแล้ว · ค้างรับ · เกินกำหนดชำระ · พิมพ์ F-18 ได้

> 💡 **ไอเดียภาพ:** เส้นทาง 2 ฝั่งคู่กัน: ฝั่งลูกค้า (วางบิล → รับเงิน) และฝั่งผู้รับเหมา (ส่งงาน → ตรวจรับ → แจ้งหนี้ → จ่าย)

## 8.6 แผนงานโครงการ (Gantt) · แท็บในหน้ารายโครงการ

- สร้างแผนเริ่มต้นให้อัตโนมัติจากวันเริ่ม-สิ้นสุดโครงการ ตามสัดส่วนมาตรฐานของงานติดตั้ง: S1 → S2 → S3 → ผลิต/รับของ → S5 ติดตั้ง (แยกรายอาคาร/ชั้น) → S6 → S7 → S8
- **แท่งแผนเติมสีตามความคืบหน้าจริงจากข้อมูลหน้างาน** · เส้นเข้มใต้แท่ง = ช่วงที่ทำจริง · เส้นแดง = วันนี้ · ◆ กำหนดเสร็จ (และหลังขยายเวลา) · ▲ วันที่ส่งมอบ
- สถานะแต่ละงาน: เสร็จแล้ว · ตามแผน · ช้ากว่าแผน (เทียบ % ที่ควรได้) · ล่าช้า n วัน
- ตัวเลขสรุป: ความคืบหน้าจริงเทียบตามแผน · ระยะเวลา · จำนวนงานล่าช้า/ช้ากว่าแผน
- แก้ไขแผนได้: วันเริ่ม-สิ้นสุด ผู้รับผิดชอบ และเพิ่มงานเอง (กรอก % เอง) · ซูมรายวัน/สัปดาห์/เดือน · ดูทุกโครงการในแผนเดียวได้

## 8.7 ผู้ใช้งานและสิทธิ์ (กำหนดละเอียด)

**สิทธิ์ 33 รายการ แบ่ง 6 กลุ่ม** — แต่ละรายการคือเมนูที่มองเห็น หรือการกระทำหนึ่งอย่าง
- **ภาพรวมและโครงการ:** ดูภาพรวม · ดูรายโครงการ · สร้าง/แก้ไขข้อมูลโครงการ · วางตำแหน่ง/มอบหมายทีม · แก้ไขแผนงาน Gantt
- **ขั้นตอนหน้างาน:** S1–S2 · S3 อนุมัติแบบ · S4 รับของ · S5 ส่งงาน · S5 ตรวจรับรายจุด · S6 QC · S7 ส่งมอบ · S8 ปิดงาน · เปิด/ปิด NCR
- **ทีมช่างและการเบิกจ่าย:** ดูหน้าทีมช่าง · ทะเบียน/สัญญา/อัตรา · ส่งเบิกงานงวด · อนุมัติเบิก · บันทึกจ่ายเงินช่าง · ออกหนังสือรับรองเงินประกัน
- **รายงานหน้างาน:** ดู/เขียน/รับทราบรายงานประจำวัน · ดู/บันทึกปัญหาหน้างาน
- **การเงินและบัญชี:** เห็นตัวเลขการเงิน · แก้ไข SO/ต้นทุน · มุมบัญชี · กระแสเงินสด · ออกใบแจ้งหนี้ลูกค้า · บันทึกรับเงิน
- **ระบบ:** แบบฟอร์ม · จัดการผู้ใช้งานและสิทธิ์

**3 ระดับการกำหนด**
1. **บทบาท** — ตารางสิทธิ์ (สิทธิ์ × บทบาท) ติ๊กเปิด/ปิดได้ทันที มี 8 บทบาทตั้งต้น คืนค่าเริ่มต้นได้ · **สร้างบทบาทใหม่**โดยคัดลอกจากบทบาทเดิม · ผู้ดูแลระบบมีทุกสิทธิ์เสมอ
2. **รายบุคคล** — ปรับจากบทบาทได้ทีละรายการ: ตามบทบาท / อนุญาตเพิ่ม / ไม่อนุญาต (เช่น โฟร์แมนคนหนึ่งให้ตรวจ QC ได้ แต่ไม่ให้ปิด NCR)
3. **โครงการที่เข้าถึง** — ทุกโครงการ หรือเลือกเฉพาะ · ผู้รับเหมาผูกกับทีมช่าง เห็นเฉพาะงานของทีมตัวเอง

- ระบบบังคับสิทธิ์ที่ปุ่มบันทึกทุกจุดสำคัญ ถ้าไม่มีสิทธิ์จะแจ้งชื่อสิทธิ์ที่ขาด
- ผู้ดูแลระบบกด **“ดูในฐานะ”** เพื่อทดสอบว่าผู้ใช้แต่ละคนเห็นอะไรและทำอะไรได้ · ต้องมีผู้ดูแลระบบอย่างน้อย 1 คน

## 8.8 ระบบเสนองาน

- บันทึกโอกาสงาน: ลูกค้า ผู้ติดต่อ สถานที่ ประเภทงาน ที่มา ผู้รับผิดชอบ มูลค่าประมาณการ % โอกาสได้งาน กำหนดยื่นราคา วันติดตามครั้งถัดไป
- **สถานะ:** รับข้อมูล → สำรวจ/ถอดแบบ → จัดทำราคา → ยื่นใบเสนอราคาแล้ว → ต่อรอง/รอผล → **ได้งาน** / ไม่ได้งาน (บันทึกเหตุผลและคู่แข่ง)
- **ใบเสนอราคาทุกครั้ง (Rev 0, 1, 2 …):** เลขที่ QT วันที่ มูลค่า ยืนราคาถึง ส่งทางไหน แนบไฟล์ · เห็นส่วนต่างราคาเทียบครั้งก่อน
- บันทึกการติดตาม (โทร ประชุม สำรวจ ส่งเอกสาร) พร้อมวันติดตามครั้งถัดไป · เมนูแสดงจำนวนงานที่ถึงกำหนดติดตาม
- มุมมองกระดานตามสถานะ หรือรายการ · ตัวเลขสรุป: มูลค่างานที่กำลังเสนอ มูลค่าถ่วงโอกาส อัตราได้งาน (ตามจำนวนและมูลค่า)
- **ได้งานแล้ว → กด “เปิดโครงการ”** ระบบสร้างโครงการพร้อมลูกค้า มูลค่า และใบเสนอราคาที่ลูกค้ายอมรับ แล้วพาไปกรอกข้อมูลโครงการต่อ

- **ออกใบเสนอราคาจากระบบ (F-00):** ใส่รายการสินค้า ค่าติดตั้ง ค่าขนส่ง (ไม่มี VAT) จำนวน ราคา ส่วนลด (บาท/%) เงื่อนไขการชำระเงิน ระยะเวลาส่งมอบ การรับประกัน หมายเหตุ ผู้เสนอราคา · คำนวณ VAT ยอดรวม และจำนวนเงินตัวอักษรให้ · Rev ใหม่คัดลอกรายการจากครั้งก่อนได้ · พิมพ์/บันทึก PDF พร้อมช่องลูกค้ายืนยันสั่งซื้อ · ปุ่มอีเมลเปิดโปรแกรมอีเมลพร้อมข้อความ · ยังแนบไฟล์ที่ทำจากระบบอื่นได้
- **สาเหตุระหว่างรอพิจารณา:** งานที่ยื่นราคาแล้ว/ต่อรอง ระบุสาเหตุที่ยังรอ (รออนุมัติงบ · เทียบราคาคู่แข่ง · รอผู้ออกแบบยืนยัน · รอผู้รับเหมาหลัก · ขอปรับสเปค · ต่อรองราคา · รอบอร์ด · รอลงนาม/PO · โครงการเลื่อน) พร้อมจำนวนวันที่รอ · สรุป “งานรอพิจารณาแยกตามสาเหตุ” บนหน้าเสนองาน

**ผู้ใช้ภายใน / ภายนอก:** หน้าผู้ใช้งานแยก 2 แท็บ · ผู้ใช้ภายนอก (ผู้รับเหมา ลูกค้า ผู้ควบคุมงาน) ต้องระบุบริษัท เลือกได้เฉพาะบทบาทภายนอก ต้องกำหนดโครงการเฉพาะ และระบบตัดสิทธิ์ด้านการเงิน ต้นทุน การอนุมัติ การเสนองาน และการจัดการผู้ใช้ออกเสมอ · เพิ่มบทบาท “ลูกค้า / ผู้ควบคุมงาน” และ “ฝ่ายขาย / ประมาณราคา”

- ทีมที่มอบ / ทีมที่ติดตั้งจริง
- เส้นทาง S1–S8 ว่าผ่านขั้นไหนแล้ว และปุ่มบันทึกขั้นถัดไป
- **ประวัติหน้างาน:** รูปสำรวจ (S2) · แบบที่ลูกค้าลงนาม (S3) · วันและทีมที่รับของ (S4) · รูปทุกจุดติดตั้ง (S5)
- NCR ทั้งหมดของบานนี้
- ประวัติการเบิกค่าแรง

> 💡 **ไอเดียภาพ:** "บัตรประจำตัวบาน" มีรูป รหัส ตำแหน่ง และแถบ 8 ขั้น

## 10. มุมมองการติดตามงาน

| มุมมอง | ใช้ทำอะไร |
|---|---|
| **ผังช่องเปิด** | เห็นทุกบานเป็นช่องสีเรียงตามชั้น สลับได้ 2 แบบ: ระบายสีตาม **สถานะ** หรือตาม **ทีมช่าง** บานที่มี NCR มีกรอบแดง |
| **กราฟจำนวนบานต่อขั้น** | เห็นว่างานกองอยู่ขั้นไหน (คอขวด) |
| **รายการ** | ตารางทุกบาน กรองตามชั้น ประเภท ทีม สถานะ |
| **S1–S3 เตรียมงาน** | ทบทวน S1 ทั้งโครงการ · สำรวจ S2 รายช่อง · อนุมัติแบบ S3 รายแบบ |
| **S4–S5 หน้างาน** | สแกนรับของ · พิมพ์ป้าย QR · ถ่ายรูปและยืนยันการติดตั้งทีละจุด |
| **NCR** | รายการปัญหาทั้งหมด เรียงตามความรุนแรงและกำหนด |

> 💡 **ไอเดียภาพ:** ตัวอย่างผังช่องสี (คล้ายผังที่นั่งในโรงหนัง) แสดงอาคาร 4 ชั้น สีไล่ตามความคืบหน้า

## 11. ตัวชี้วัด (KPI) ที่ระบบวัดให้อัตโนมัติ

| KPI | เป้าหมายตั้งต้น |
|---|---|
| ผ่าน QC ครั้งแรก | ≥ 95% |
| ผ่านทดสอบน้ำ | ≥ 98% |
| ข้อบกพร่องต่อ 100 บาน | ≤ 5 |
| ปิด NCR ระดับ A ตามกำหนด | 100% |
| % ใช้งบเทียบ % งานที่ทำได้ | ไม่เร็วกว่างานเกิน 10% |
| สถานะเวลาโครงการ | ไม่ "ช้ากว่าแผน" หรือ "เลยกำหนด" |

ตัวเลขที่ต่ำกว่าเป้าจะเปลี่ยนเป็นสีส้มหรือแดงให้เห็นทันที

## 12. ระบบป้องกันความผิดพลาด (จุดขายสำหรับผู้บริหาร)

| ความเสี่ยงเดิม | ระบบป้องกันอย่างไร |
|---|---|
| นำเข้า SO ผิดโครงการ | ตรวจรหัสลูกค้า SAP ให้อัตโนมัติ |
| บานไม่มีที่อยู่ ติดผิดห้อง | ทุกบานต้องมีอาคาร ชั้น ห้อง · วางเกินจำนวนใน SO ไม่ได้ |
| สำรวจหน้างานไม่ครบ ไม่มีหลักฐาน | S2 ต้องมีรูปถ่ายและชื่อผู้ยืนยันทุกช่อง |
| ผลิตตามแบบที่ลูกค้ายังไม่อนุมัติ | S3 ต้องแนบ Shop drawing ที่ลูกค้าลงนามก่อน |
| ของส่งผิดไซต์ หรือไม่รู้ว่าของถึงหรือยัง | S4 สแกนรับ ตรวจโครงการและกันรับซ้ำ |
| ติดตั้งแล้วไม่มีหลักฐาน ซ่อนงานใต้ sealant | S5 ต้องมีรูปทุกจุดตรวจ (เฟรม · บาน · sealant) |
| ทำงานโดยไม่มีหลักฐานการว่าจ้าง | ต้องแนบ QT ลูกค้าลงนาม และ MOA ช่างที่ลงนาม |
| ขยายเวลาโดยไม่มีหลักฐาน | ต้องแนบหนังสือขอขยายเวลา และอ้างอิงบันทึกปัญหาหน้างาน |
| ข้ามขั้นตอนตรวจ | จุดหยุดตรวจต้องยืนยันการลงนามก่อน |
| ส่งมอบทั้งที่ยังมีปัญหา | มี NCR ค้าง ส่งมอบไม่ได้ |
| จ่ายค่าแรงซ้ำหรือจ่ายก่อนงานผ่าน | จ่ายตามงวดที่ผ่าน QC เท่านั้น · เบิกซ้ำไม่ได้ |
| งบบานปลายโดยไม่รู้ตัว | เทียบงบกับใช้จริงทุกหมวด · เตือนเมื่อค่าแรงเดินเร็วกว่างาน |
| ไม่รู้ว่าใครทำเสียหาย | NCR ระบุสาเหตุและผู้รับผิดชอบทุกรายการ |

> 💡 **ไอเดียภาพ:** 2 คอลัมน์ "ก่อน" (ไอคอนเตือน) → "หลัง" (ไอคอนโล่) 11 แถว

## 13. การใช้งานและการแบ่งสิทธิ์

- ใช้ผ่านเว็บเบราว์เซอร์ ทั้งคอมพิวเตอร์และมือถือ (ช่างถ่ายรูปหน้างานจากมือถือได้ทันที)
- เมื่อเผยแพร่ใช้จริง **ทุกคนเห็นข้อมูลชุดเดียวกันแบบเรียลไทม์** ไม่ต้องส่งไฟล์ไปมา
- แบ่งสิทธิ์ได้ (ข้อเสนอ):
  - **ผู้บริหาร / ผู้มีสิทธิ์แก้ไข:** เห็นทุกอย่าง รวมตัวเลขการเงิน
  - **ทีมหน้างาน (โฟร์แมน, QC, ช่าง):** บันทึกงานได้ แต่ไม่เห็นตัวเลขการเงิน
  - **ผู้ดูอย่างเดียว:** ดูได้ บันทึกไม่ได้

## 14. ภาพรวมการไหลของข้อมูล (สำหรับภาพสรุปหน้าสุดท้าย)

```
SAP (SO, PO) ──► ระบบควบคุมงานติดตั้ง ──► ผู้บริหาร
                    │                       (ภาพรวม · กำไร · ความเสี่ยง)
หน้างาน ──────────► │
(รูป · สแกน · QC)   ├──► ทีมช่าง (งานที่ได้รับ · ค่าแรงที่เบิกได้)
                    └──► บัญชี (มูลค่าวางบิล · ยอดเบิกค่าแรง)
```

**ประโยชน์หลัก 4 ข้อ**
1. **เห็นทุกบาน ทุกโครงการ** ในหน้าจอเดียว
2. **คุณภาพมีหลักฐาน** แบบมีลายเซ็นลูกค้า รับของด้วยการสแกน และมีรูปทุกจุดติดตั้ง
3. **เงินชัดเจน** รู้รายได้ ต้นทุน กำไร และจ่ายค่าแรงตามงานที่ผ่านจริง
4. **ปัญหาไม่ตกหล่น** NCR ทุกรายการมีเจ้าของ กำหนดเวลา และสัญญาณเตือน
