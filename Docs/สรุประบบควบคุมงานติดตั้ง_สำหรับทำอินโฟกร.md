- เอกสารเขียนด้วย **ภาษาธุรกิจ ไม่ใช้ศัพท์ไอที** ศัพท์เฉพาะทุกคำมีคำอธิบายในหัวข้อ "อภิธานศัพท์" ท้ายเอกสาร

# ส่วนที่ 1 · ภาพรวม

## 1. ระบบนี้คืออะไร แก้ปัญหาอะไร

🎯 **ข้อความหลัก:** "ติดตามงานติดตั้งทุกบาน ตั้งแต่ได้งานจนปิดโครงการ ในระบบเดียว"

**ระบบนี้คือ** สมุดคุมงานกลางของบริษัทที่ทุกฝ่ายใช้ร่วมกัน ตั้งแต่ฝ่ายขาย ผู้จัดการโครงการ ช่างหน้างาน QC บัญชี ไปจนถึงผู้บริหาร โดยติดตามงานละเอียดถึง **ระดับบาน (ช่องเปิดทีละช่อง)**

💡 **ปัญหาเดิมที่ระบบแก้**

| ปัญหาเดิม | ระบบแก้อย่างไร |
|---|---|
| ไม่รู้ว่าแต่ละบานถึงขั้นไหนแล้ว ต้องโทรถามหน้างาน | เห็นสถานะทุกบานแบบปัจจุบัน แยกตามอาคาร ชั้น ห้อง |
| ข้อมูลกระจายอยู่ในไลน์ อีเมล กระดาษ และ Excel หลายไฟล์ | ข้อมูลอยู่ที่เดียว ทุกฝ่ายเห็นตรงกัน |
| จ่ายค่าจ้างช่างก่อนงานเสร็จ หรือจ่ายซ้ำ | จ่ายเฉพาะงานที่บริษัทตรวจรับแล้ว และระบบกันการเบิกซ้ำ |
| ส่งมอบงานแล้วไม่มีหลักฐานลูกค้าลงนาม | ต้องแนบเอกสารที่ลูกค้าลงนามก่อนบันทึกส่งมอบ |
| รู้ต้นทุนจริงตอนจบโครงการ ซึ่งช้าเกินไป | เห็นต้นทุนเทียบงบระหว่างทาง พร้อมสัญญาณเตือน |
| ไม่รู้ว่าเงินจะเข้า-ออกเมื่อไร | มีภาพกระแสเงินสดและคาดการณ์ล่วงหน้า 90 วัน |
| ผลิตผิดขนาด ติดผิดตำแหน่ง | บังคับมีรูปสำรวจ แบบที่ลูกค้าอนุมัติ และสแกนรหัสบานก่อนรับของ |
| ขอขยายเวลาไม่ได้ เพราะไม่มีบันทึกอุปสรรค | บันทึกปัญหาพร้อมผู้รับผิดชอบสาเหตุ และนับจำนวนวันที่ใช้ขอขยายเวลาได้ |

🎨 **ข้อเสนอการจัดภาพ:** แบบ "ก่อน vs หลัง" สองคอลัมน์ ฝั่งซ้ายสีเทา (ปัญหา) ฝั่งขวาสีน้ำเงิน (ทางแก้)

## 4. เส้นทางของงานหนึ่งงาน ตั้งแต่ต้นจนจบ

🎯 **ข้อความหลัก:** "จากใบเสนอราคา ถึงวันปิดโครงการ ทุกขั้นอยู่ในระบบ"

### 4.1 เส้นหลัก (งานหน้างาน)

```
เสนองาน → ได้งาน → ตั้งค่าโครงการ → S1–S3 เตรียมงาน → S4–S5 ติดตั้ง → S6 ตรวจคุณภาพ → S7 ส่งมอบ → S8 ปิดงาน
```

### 4.2 เส้นคู่ขนาน (งานเงิน)

```
มอบงานให้ทีมช่าง → ช่างส่งงาน / บริษัทตรวจรับ → เบิกจ่ายค่าจ้าง → วางบิลลูกค้า → รับเงิน → ปิดโครงการ / คืนเงินประกัน
```

### 4.3 แบ่ง 4 ช่วง

| ช่วง | ชื่อช่วง | เกิดอะไรขึ้น | ใครเป็นหลัก | ผลที่ได้ |
|---|---|---|---|---|
| 1 | **การขาย** | บันทึกโอกาสงาน ทำใบเสนอราคา ติดตามลูกค้า จนได้งาน | ฝ่ายขาย | ใบเสนอราคาที่ลูกค้ายอมรับ |
| 2 | **เปิดโครงการ** | กรอกข้อมูลโครงการ นำรายการสินค้าเข้า วางตำแหน่งบาน มอบหมายทีม ทำสัญญาผู้รับเหมา | ผู้จัดการโครงการ บัญชี | โครงการพร้อมเริ่มงาน ทุกบานมีรหัส |
| 3 | **ควบคุมงานติดตั้ง** | 8 ขั้นตอนรายบาน ตั้งแต่สำรวจจนปิดงาน | วิศวกร QC โฟร์แมน ทีมช่าง | งานผ่านคุณภาพ ลูกค้าลงนามรับมอบ |
| 4 | **การเงิน (เดินคู่กันตลอด)** | ค่าแรงทีมภายใน เบิกจ่ายผู้รับเหมา วางบิลลูกค้า ติดตามเงินสด | บัญชี ผู้บริหาร | ต้นทุนและกระแสเงินสดที่เห็นได้ทุกวัน |

# ส่วนที่ 2 · ก่อนเริ่มงาน

## 6. ระบบเสนองาน

🎯 **ข้อความหลัก:** "ทุกโอกาสงานถูกติดตาม ไม่มีลูกค้าหลุดมือ"

💡 **ทำไมสำคัญ**
- เห็นมูลค่างานที่กำลังเสนอทั้งหมด และโอกาสได้งาน
- รู้ว่างานไหนถึงเวลาต้องโทรตาม
- เก็บประวัติใบเสนอราคาทุกครั้ง ไม่ต้องค้นจากอีเมล
- ได้งานแล้วเปิดโครงการต่อได้ทันที โดยไม่ต้องกรอกข้อมูลซ้ำ

### 6.1 สถานะของงานที่เสนอ (9 สถานะ)

```
รับข้อมูล → สำรวจ / ถอดแบบ → จัดทำราคา → ยื่นใบเสนอราคา → ต่อรอง / รอผล → ได้งาน
                                                                            ↘ ไม่ได้งาน
                                                                            ↘ ยกเลิก
```

| สถานะ | ความหมาย |
|---|---|
| รับข้อมูล | มีลูกค้าสนใจ เพิ่งได้ข้อมูลเบื้องต้น |
| สำรวจ / ถอดแบบ | ไปดูพื้นที่ หรือนับจำนวนบานจากแบบ |
| จัดทำราคา | กำลังคิดราคา |
| ยื่นใบเสนอราคาแล้ว | ส่งราคาให้ลูกค้าแล้ว |
| ต่อรอง / รอผล | ลูกค้ากำลังพิจารณาหรือขอต่อรอง |
| ได้งาน | ลูกค้าตกลง พร้อมเปิดโครงการ |
| ไม่ได้งาน | บันทึกเหตุผลและคู่แข่ง เพื่อเรียนรู้ |
| ยกเลิก | ลูกค้ายกเลิกโครงการ |

### 6.2 ข้อมูลที่บันทึกในแต่ละโอกาสงาน
- ลูกค้า รหัสลูกค้า ผู้ติดต่อ เบอร์โทร
- สถานที่ ประเภทงาน (คอนโด บ้าน อาคารสำนักงาน ฯลฯ) ที่มาของงาน
- ผู้รับผิดชอบฝั่งขาย
- มูลค่าประมาณการ และ **% โอกาสได้งาน**
- กำหนดยื่นราคา วันที่คาดว่าจะเริ่มงาน จำนวนบานโดยประมาณ

### 6.3 ตัวเลขสรุปบนหน้าระบบเสนองาน
- **มูลค่างานที่กำลังเสนอ** รวมทุกงานที่ยังไม่ปิด
- **มูลค่าถ่วงโอกาส** คือมูลค่าคูณ % โอกาส ใช้ประเมินยอดขายที่คาดว่าจะได้จริง
- **อัตราได้งาน** ทั้งตามจำนวนงานและตามมูลค่า
- **ใบเสนอราคาที่ส่งเดือนนี้**
- **งานที่ถึงกำหนดติดตาม** (แสดงตัวเลขเตือนบนเมนู)

### 6.4 มุมมอง 2 แบบ
- **กระดาน:** การ์ดงานเรียงตามสถานะเป็นคอลัมน์ เห็นภาพว่างานกองอยู่ขั้นไหน
- **รายการ:** ตารางเรียงตามมูลค่าหรือกำหนดเวลา

🎨 **ข้อเสนอการจัดภาพ:** ภาพกรวย (funnel) จากกว้างไปแคบ แสดงสถานะ พร้อมกล่องตัวเลข 4 กล่องด้านข้าง

## 7. ใบเสนอราคาจากระบบ

🎯 **ข้อความหลัก:** "ออกใบเสนอราคามาตรฐานได้ในไม่กี่นาที คำนวณให้อัตโนมัติ"

### 7.1 ขั้นตอน
1. เลือกงานที่เสนอ แล้วกด "สร้างใบเสนอราคา"
2. ใส่รายการแยก 3 หมวด: **สินค้า · ค่าติดตั้ง · ค่าขนส่ง** (ขนาด จำนวน หน่วย ราคา)
3. ใส่ส่วนลด เป็นบาทหรือ %
4. ระบบคำนวณ VAT ยอดรวม และ **จำนวนเงินเป็นตัวอักษรภาษาไทย** ให้อัตโนมัติ
5. ใส่เงื่อนไข: การชำระเงิน ระยะส่งมอบ การรับประกัน ยืนราคาถึงวันที่
6. บันทึก แล้วพิมพ์หรือบันทึกเป็น PDF (แบบฟอร์ม F-00) มีช่องให้ลูกค้าลงนามยืนยันสั่งซื้อ
7. บันทึกวันที่และช่องทางที่ส่ง (อีเมล LINE ยื่นเอง ระบบของลูกค้า) หรือกดปุ่มเปิดอีเมลพร้อมข้อความ

### 7.2 จุดเด่น
- ⭐ **ค่าขนส่งไม่คิด VAT** ระบบแยกให้อัตโนมัติ ลดความผิดพลาด
- ⭐ **ปรับราคาได้หลายครั้ง** (Rev 0, 1, 2 …) ทุกครั้งถูกเก็บไว้ และแสดงส่วนต่างราคาจากครั้งก่อน
- ⭐ **คัดลอกรายการจากครั้งก่อน** มาแก้ต่อได้ ไม่ต้องพิมพ์ใหม่
- ⭐ **เตือนเมื่อใบเสนอราคาหมดอายุ** (เลยวันยืนราคา)
- ⭐ แนบไฟล์ใบเสนอราคาที่ทำจากที่อื่นได้ ถ้าต้องการ

🎨 **ข้อเสนอการจัดภาพ:** ภาพจำลองใบเสนอราคา มีลูกศรชี้จุดที่ระบบคำนวณให้ (VAT ยอดรวม จำนวนเงินตัวอักษร) และไอคอนกองกระดาษ Rev 0 → Rev 1 → Rev 2

## 8. การติดตามและสาเหตุที่ลูกค้ายังไม่ตัดสินใจ

🎯 **ข้อความหลัก:** "รู้ว่าลูกค้ารออะไร และรอมานานเท่าไร"

### 8.1 บันทึกการติดตาม
- ประเภท: โทร · ประชุม · สำรวจ · ส่งเอกสาร
- ทุกครั้งกำหนด **วันติดตามครั้งถัดไป** ระบบเตือนเมื่อถึงกำหนด

### 8.2 สาเหตุระหว่างรอพิจารณา (เลือกได้ 9 แบบ)

| สาเหตุ | ตัวอย่าง |
|---|---|
| รออนุมัติงบประมาณ | ลูกค้ายังไม่ได้งบ |
| เทียบราคากับคู่แข่ง | ลูกค้าขอราคาหลายเจ้า |
| รอผู้ออกแบบ / สถาปนิกยืนยัน | สเปคยังไม่นิ่ง |
| รอผู้รับเหมาหลัก | ผู้รับเหมาหลักยังไม่ตัดสินใจ |
| ขอปรับสเปค | ลูกค้าอยากเปลี่ยนรุ่นหรือขนาด |
| ต่อรองราคา | อยู่ระหว่างเจรจา |
| รอที่ประชุม / บอร์ดอนุมัติ | รอการประชุมของลูกค้า |
| รอลงนามสัญญา / ออก PO | ตกลงแล้ว รอเอกสาร |
| โครงการเลื่อน | ลูกค้าเลื่อนแผน |

- ระบบ **นับจำนวนวันที่รอ** ในแต่ละสาเหตุ
- สรุป **แยกตามสาเหตุ** ว่ามีกี่งาน มูลค่าเท่าไร เพื่อให้ผู้บริหารรู้ว่าคอขวดอยู่ตรงไหน

### 8.3 เมื่อได้งาน / ไม่ได้งาน
- **ได้งาน:** ระบุว่าใบเสนอราคาครั้งไหนที่ลูกค้ายอมรับ แล้วกด "เปิดโครงการ" ระบบนำลูกค้า มูลค่า และใบเสนอราคาไปตั้งโครงการให้
- **ไม่ได้งาน:** บันทึกเหตุผลและคู่แข่ง

🎨 **ข้อเสนอการจัดภาพ:** แผนภูมิแท่งแนวนอน "งานที่รอ แยกตามสาเหตุ" พร้อมไอคอนนาฬิกาทรายแสดงจำนวนวันรอ

## 9. การเปิดโครงการและตั้งค่า 6 ขั้น

🎯 **ข้อความหลัก:** "ตั้งค่าครบ 6 ขั้น ก่อนเริ่มงาน ทุกบานพร้อมติดตาม"

| ขั้น | ชื่อ | สิ่งที่ทำ |
|---|---|---|
| 1 | **เปิดโครงการ** | รหัสโครงการ ชื่อ ลูกค้า รหัสลูกค้าใน SAP · เลขที่ใบเสนอราคาและไฟล์ที่ลงนาม (หลายฉบับได้) |
| 2 | **ระยะเวลาและงบประมาณ** | วันเริ่ม-วันเสร็จ · งบค่าสินค้า ค่าแรง ค่าใช้จ่ายอื่น · การขยายเวลาต้องแนบหนังสือ · งานเพิ่ม (VO) เพิ่มทั้งมูลค่าและงบ |
| 3 | **รายการสินค้าและรายได้ (SO)** | นำรายการขายจาก SAP เข้าระบบ หรือเพิ่มเอง · เลือกวิธีคิดมูลค่าโครงการ |
| 4 | **ตำแหน่งติดตั้ง** | สร้างอาคาร ชั้น ห้อง แล้ววางบานลงตำแหน่ง ระบบสร้างรหัสบานและป้าย QR ให้ |
| 5 | **ทีมและการมอบหมาย** | เลือกทีมเข้าโครงการ แล้วมอบงานรายชั้นหรือรายบาน |
| 6 | **ค่าจ้างผู้รับเหมา** | กำหนดอัตราต่อตารางเมตรหรือต่อบาน (ทีมภายในคิดตามชั่วโมง) |

ความคืบหน้าของ 6 ขั้นแสดงเป็นแถบด้านบนของหน้าโครงการ เห็นทันทีว่าขาดอะไร

### 9.1 วิธีคิดมูลค่าโครงการ 4 แบบ

| แบบ | ความหมาย |
|---|---|
| รับเหมาติดตั้งพร้อมขนส่ง | คิดค่าสินค้า ค่าติดตั้ง ค่าขนส่ง |
| แยกขาย | ขายสินค้าอย่างเดียว |
| ฟรีค่าติดตั้ง คิดค่าขนส่ง | ไม่คิดค่าติดตั้ง |
| ฟรีค่าติดตั้งและค่าขนส่ง | คิดเฉพาะสินค้า |

- ดูมูลค่าได้ทั้งแบบรวมและไม่รวม VAT
- **ค่าขนส่งไม่มี VAT**

### 9.2 การตั้งจุดตรวจรับงานติดตั้ง
- **แบบจุดเดียว:** ช่างติดตั้งเสร็จ 100% แล้วส่งตรวจครั้งเดียว
- **แบบหลายจุด:** แบ่งงานเป็นช่วง และกำหนด % ให้รวมกันได้ 100 เช่น
  - ติดตั้งวงกบ **40%** → ติดตั้งบาน **40%** → ยาแนว **20%**
  - ตรวจรับทีละจุด ช่างได้เงินตามจุดที่ผ่าน
  - **ล็อกห้ามแก้** เมื่อเริ่มงานแล้ว เพื่อความเป็นธรรมและกันการแก้ย้อนหลัง

🎨 **ข้อเสนอการจัดภาพ:** บันได 6 ขั้น หรือแถบความคืบหน้า 6 ช่อง และภาพบานหน้าต่างที่แบ่งสี 40/40/20

- 🟨 **หน้างาน (S4–S5):** รับของถูกบาน ติดถูกที่ มีรูปยืนยันทุกจุด
- 🟩 **ส่งมอบและปิด (S6–S8):** คุณภาพผ่าน ลูกค้าลงนาม เอกสารครบ

🎨 **ข้อเสนอการจัดภาพ:** เส้นทาง 8 สถานี (แบบแผนที่รถไฟฟ้า) สถานีที่มี ◆ ใช้สัญลักษณ์ประตูกั้น แบ่ง 3 สี

## 11. รายละเอียดทีละขั้น

### S1 · ทบทวนสัญญาและแบบ
- ทำครั้งเดียวต่อโครงการ ก่อนเริ่มสำรวจ
- ยืนยันว่าเข้าใจสัญญา แบบ ขอบเขตงาน และเงื่อนไขตรงกันทุกฝ่าย (เช็กลิสต์ 6 ข้อ)
- 💡 กันปัญหา "ทำไปแล้วไม่ตรงสัญญา"

### S2 · สำรวจหน้างาน ◆
- วิศวกรถ่ายรูปช่องเปิดจริงทีละบาน
- บานที่ชื่อตามแบบเหมือนกันใช้รูปร่วมกันได้ แต่ **ยังต้องยืนยันทีละบาน**
- พิมพ์ใบสำรวจ F-01
- 💡 กันปัญหา **ผลิตผิดขนาด** ซึ่งเป็นความเสียหายที่แพงที่สุด

### S3 · อนุมัติแบบผลิต ◆
- อนุมัติทีละแบบ แบบเดียวครอบคลุมหลายบาน
- **ต้องแนบไฟล์แบบที่ลูกค้าลงนาม** จึงจะผ่าน
- บานที่ยังไม่ผ่าน S3 จะรับของที่หน้างานไม่ได้
- 💡 มีหลักฐานว่าลูกค้าเห็นชอบแบบก่อนผลิต

### S4 · รับของหน้างาน
- ใช้กล้องมือถือสแกนป้าย QR ที่ตัวบาน หรือพิมพ์รหัส
- **รับได้เฉพาะทีมที่ได้รับมอบหมาย** บานนั้น
- แจ้งของเสียหายได้ทันทีพร้อมรูป
- 💡 รู้ว่าของถึงหน้างานแล้วกี่บาน ของหายหรือเสียหายตรงไหน

### S5 · ติดตั้ง
- ช่างถ่ายรูปทุกจุดที่ทำเสร็จแล้วกดส่ง
- โฟร์แมนหรือ QC **ตรวจรับ** หรือ **ตีกลับพร้อมเหตุผล**
- งานที่ตรวจรับแล้วนำไปคิด **ค่าจ้างผู้รับเหมา** และ **รายได้ตามความคืบหน้า** ทันที
- 💡 จ่ายเงินตรงกับงานจริง และเห็นความคืบหน้าแบบวันต่อวัน

### S6 · ตรวจรับงานติดตั้ง (QC) ◆
- ตรวจ 3 ด้าน: **การใช้งาน** (เปิด-ปิด ล็อก) · **ความสะอาด** · **ทดสอบน้ำ**
- ทดสอบน้ำแบบสุ่ม **อย่างน้อย 10%** ต่อชั้นต่อประเภทบาน
- **ถ้าไม่ผ่าน ต้องเปิดใบแจ้งข้อบกพร่อง (NCR) ทันที** จะบันทึกว่าไม่ผ่านเฉย ๆ ไม่ได้
- ข้อบกพร่องระดับ A หรือ B ที่ยังไม่ปิด ทำให้บานนั้นผ่าน S6 ไม่ได้
- ดูสถิติ **ผ่าน QC ครั้งแรก** เป้าหมาย **≥ 95%**
- หน้าตรวจแยกอาคาร ชั้น และกรองได้: รอตรวจ / ไม่ผ่าน / ผ่านแล้ว

### S7 · ส่งมอบงาน ◆
1. เลือกบานที่พร้อม (ผ่าน S6 ไม่มีข้อบกพร่องค้าง) เป็นชุด เช่น ทั้งชั้น
2. พิมพ์หนังสือส่งมอบ F-07
3. ลูกค้าตรวจและลงนาม
4. **แนบไฟล์ที่ลงนามแล้ว (บังคับ)** แล้วจึงบันทึกได้
- มีทะเบียนหนังสือส่งมอบ พิมพ์ซ้ำได้
- ยกเลิกได้ถ้ายังไม่ปิดงานและยังไม่วางบิล

### S8 · ปิดงานและปิดโครงการ ◆
- ปิดรายบานก่อน แล้วจึงปิดทั้งโครงการ
- **ระบบตรวจอัตโนมัติ 7 ข้อ**
  1. ส่งมอบครบทุกบาน
  2. ปิดงานรายบานครบ
  3. ข้อบกพร่อง (NCR) ปิดครบ
  4. ปัญหาหน้างานปิดครบ
  5. วางบิลลูกค้าครบตามมูลค่าสัญญา
  6. รับเงินจากลูกค้าครบ
  7. จ่ายค่าจ้างช่างครบ
- **เอกสารท้ายโครงการ 6 รายการ**
  1. ใบรับประกันสินค้า
  2. ใบรับประกันงานติดตั้ง
  3. คู่มือการใช้งานและบำรุงรักษา
  4. แบบก่อสร้างจริง (As-built)
  5. คืนพื้นที่และทำความสะอาด
  6. ส่งมอบกุญแจ อุปกรณ์ อะไหล่สำรอง
- ครบทุกข้อจึงกดปิดโครงการได้ ใส่ระยะรับประกัน ระบบคำนวณวันหมดประกัน แล้วพิมพ์บันทึกปิดงาน F-08

🎨 **ข้อเสนอการจัดภาพ:** แผ่นละขั้น หรือรวมในแผ่นเดียวแบบการ์ด 8 ใบ แต่ละใบมี "ทำอะไร · หลักฐาน · กันปัญหาอะไร" สำหรับ S8 ใช้เช็กลิสต์ 7 + 6 ช่อง

## 12. ใบแจ้งข้อบกพร่อง (NCR)

🎯 **ข้อความหลัก:** "ทุกข้อบกพร่องมีเจ้าของ มีกำหนดแก้ และต้องปิดก่อนส่งมอบ"

### 12.1 ระดับความรุนแรง

| ระดับ | ความหมาย | ต้องแก้ภายใน |
|---|---|---|
| **A** | ร้ายแรง กระทบการใช้งานหรือความปลอดภัย | **3 วัน** |
| **B** | ปานกลาง | **7 วัน** |
| **C** | เล็กน้อย | ก่อนส่งมอบ |

### 12.2 สาเหตุที่บันทึก
วัดผิด · ผลิตผิด · ขนส่งเสียหาย · ติดตั้งผิด · ผู้อื่นทำเสียหาย

### 12.3 ขั้นตอน
```
พบข้อบกพร่อง → เปิด NCR (ระดับ สาเหตุ ผู้รับผิดชอบ รูป) → แก้ไข → QC ตรวจซ้ำ → ผ่าน → ปิด NCR
```

### 12.4 กฎสำคัญ
- QC บันทึก "ไม่ผ่าน" ได้ต้องเปิด NCR พร้อมกัน
- NCR ระดับ A/B ค้าง ทำให้บานนั้นผ่าน S6 ไม่ได้
- NCR ค้าง ทำให้ส่งมอบและปิดโครงการไม่ได้
- พิมพ์ใบ NCR (F-09) ได้
- 💡 รู้ว่าข้อบกพร่องเกิดจากฝ่ายไหนบ่อยที่สุด เพื่อแก้ที่ต้นเหตุ

🎨 **ข้อเสนอการจัดภาพ:** ไฟจราจร 3 สี (แดง A / เหลือง B / เขียว C) และวงจรแก้ไข 5 ขั้น

## 13. ปัญหาหน้างานและการขอขยายเวลา

🎯 **ข้อความหลัก:** "บันทึกอุปสรรคทุกวัน เป็นหลักฐานขอขยายเวลาได้"

### 13.1 ข้อมูลที่บันทึก
- ประเภทปัญหา (พื้นที่ไม่พร้อม แบบเปลี่ยน ของมาช้า ฝนตก ฯลฯ) และระดับ
- ตำแหน่ง และ **บานที่ได้รับผลกระทบ**
- **ผู้รับผิดชอบสาเหตุ** เช่น บริษัทเอง ลูกค้า ผู้รับเหมาหลัก หรือเหตุภายนอก
- วันที่เริ่มกระทบ วันที่แก้ได้ ค่าใช้จ่ายที่เกิดขึ้น
- เลขที่หนังสือแจ้งลูกค้า

### 13.2 ประโยชน์
- ⭐ ระบบ **นับจำนวนวันที่กระทบจากสาเหตุภายนอก** ใช้เป็นฐานขอขยายเวลา
- ⭐ พิมพ์รายงานปัญหา (F-11) และ **หนังสือขอขยายระยะเวลา (F-12)** จากระบบ
- ⭐ ลดความเสี่ยงค่าปรับล่าช้า เพราะมีหลักฐานย้อนหลังครบ

🎨 **ข้อเสนอการจัดภาพ:** ปฏิทินที่ระบายสีวันที่ถูกกระทบ → ลูกศร → หนังสือขอขยายเวลา

## 14. รายงานประจำวัน

🎯 **ข้อความหลัก:** "สมุดหน้างานดิจิทัล ผู้จัดการเห็นทุกเย็น"

**สิ่งที่บันทึกในแต่ละวัน**

- 🌦️ สภาพอากาศ และชั่วโมงที่หยุดเพราะฝน
- 👷 กำลังคนแยกตามทีม
- 🪟 **ผลงานวันนี้** ระบบนับจากการบันทึกจริงให้อัตโนมัติ ไม่ต้องนับเอง
- 🧰 วัสดุ เครื่องมือ
- 🦺 ความปลอดภัย
- ⚠️ ปัญหาที่พบ
- 📅 แผนงานพรุ่งนี้
- 📷 รูปประกอบ

**ขั้นตอน:** โฟร์แมนบันทึก → ผู้จัดการโครงการกด "รับทราบ" → พิมพ์รายงาน F-10 ได้

🎨 **ข้อเสนอการจัดภาพ:** หน้าสมุดบันทึกพร้อมไอคอน 9 ช่อง

## 15. แผนงานโครงการ (Gantt)

🎯 **ข้อความหลัก:** "แผนเทียบงานจริง เห็นทันทีว่างานไหนช้า"

### 15.1 การทำงาน
- ระบบ **สร้างแผนเริ่มต้นให้อัตโนมัติ** จากวันเริ่มและวันเสร็จ เรียงตามขั้นตอน: S1 → S2 → S3 → ผลิต/รับของ → ติดตั้ง (แยกรายอาคาร/ชั้น) → ตรวจคุณภาพ → ส่งมอบ → ปิดงาน
- **แท่งแผนงานเติมสีตามความคืบหน้าจริง** จากข้อมูลหน้างาน ไม่ต้องอัปเดตเอง

### 15.2 สัญลักษณ์บนแผน
| สัญลักษณ์ | ความหมาย |
|---|---|
| แท่งสี | ช่วงเวลาตามแผน และส่วนที่ทำเสร็จแล้ว |
| เส้นใต้แท่ง | ช่วงที่ทำจริง |
| เส้นแดงแนวตั้ง | วันนี้ |
| ◆ | กำหนดเสร็จ (และกำหนดใหม่หลังขยายเวลา) |
| ▲ | วันส่งมอบ |

### 15.3 สถานะของแต่ละงาน
- ✅ เสร็จแล้ว
- 🟢 ตามแผน
- 🟡 ช้ากว่าแผน (บอกว่าควรได้กี่ %)
- 🔴 ล่าช้า n วัน

### 15.4 อื่น ๆ
- ตัวเลขสรุป: ความคืบหน้าจริงเทียบตามแผน ระยะเวลา จำนวนงานล่าช้า
- แก้วันที่ ผู้รับผิดชอบ และเพิ่มงานเองได้
- ซูมดูเป็นวัน สัปดาห์ หรือเดือน
- **ดูทุกโครงการในผังเดียว** สำหรับผู้บริหาร

🎨 **ข้อเสนอการจัดภาพ:** ภาพแผนงานแนวนอนอย่างง่าย 5–6 แถว มีเส้นแดง "วันนี้" และป้ายสถานะสีเขียว เหลือง แดง

## 16. ทีมช่าง 2 แบบ: ภายในและผู้รับเหมา

🎯 **ข้อความหลัก:** "ทีมภายในคิดตามชั่วโมง ผู้รับเหมาคิดตามผลงาน แยกชัดเจน"

| เรื่อง | 🏢 ทีมช่างภายใน | 🤝 ผู้รับเหมาภายนอก |
|---|---|---|
| คือใคร | พนักงานของบริษัท | ผู้รับจ้างช่วงจากภายนอก |
| ต้องมีสัญญา | ไม่ต้อง (มอบหมายเข้าโครงการ) | **ต้องมีสัญญา (MOA) ลงนาม** |
| คิดค่าแรงอย่างไร | **ชั่วโมงทำงาน × ค่าแรงตามตำแหน่ง** | **ค่าจ้างตามผลงานที่ตรวจรับแล้ว** (ต่อ ตร.ม. หรือต่อบาน) |
| บันทึกอะไร | ชั่วโมงทำงานรายวัน ชั่วโมงล่วงเวลา (OT) | ส่งงาน ส่งเบิก ใบแจ้งหนี้ |
| การจ่ายเงิน | ผ่านเงินเดือน | ผ่านระบบเบิกจ่ายเป็นงวด |
| มัดจำ / เงินประกัน | ไม่มี | มีมัดจำ หักงวดตรวจรับ และเงินประกันผลงาน |
| ตัวเลขสำคัญ | ค่าแรงต่อบานที่ติดตั้ง | ยอดค้างจ่าย เงินประกันคงเหลือ |

- หน้าทีมช่างมีปุ่มสลับ **"ทีมภายใน" / "ผู้รับเหมาภายนอก"** แต่ละฝั่งมีแท็บ ตัวเลขสรุป และข้อมูลของตัวเอง ไม่ปนกัน

🎨 **ข้อเสนอการจัดภาพ:** เปรียบเทียบสองฝั่ง ฝั่งซ้ายไอคอนอาคารบริษัท ฝั่งขวาไอคอนจับมือ

## 17. ทีมช่างภายใน

🎯 **ข้อความหลัก:** "รู้ต้นทุนค่าแรงจริงจากชั่วโมงทำงานจริง"

### 17.1 ขั้นตอน
```
ทะเบียนทีมและพนักงาน → กำหนดตำแหน่งและค่าแรง → มอบหมายเข้าโครงการ → มอบงานรายบาน → บันทึกชั่วโมงทำงาน → ต้นทุนค่าแรงจริง
```

### 17.2 ค่าแรงตามตำแหน่ง (ค่าตั้งต้น แก้ไขได้)

| ตำแหน่ง | ค่าแรงต่อชั่วโมง |
|---|---|
| หัวหน้าช่าง | 125 บาท |
| ช่างฝีมือ | 95 บาท |
| ช่างทั่วไป | 75 บาท |
| ผู้ช่วยช่าง | 62 บาท |

- ชั่วโมงทำงานปกติ **8 ชั่วโมงต่อวัน**
- ค่าล่วงเวลา (OT) **1.5 เท่า**
- กำหนดค่าแรงเฉพาะรายบุคคลได้ (เช่น ช่างอาวุโส)

### 17.3 สูตรค่าแรง (อธิบายแบบง่าย)
> **ค่าแรง = (ชั่วโมงปกติ × ค่าแรงต่อชั่วโมง) + (ชั่วโมง OT × ค่าแรงต่อชั่วโมง × 1.5)**

ตัวอย่าง: ช่างฝีมือทำงาน 8 ชั่วโมง + OT 2 ชั่วโมง = (8 × 95) + (2 × 95 × 1.5) = 760 + 285 = **1,045 บาท**

### 17.4 แท็บของทีมภายใน
| แท็บ | ใช้ทำอะไร |
|---|---|
| ภาพรวมทีมภายใน | จำนวนทีมและพนักงาน · บานที่มอบหมายและติดตั้งแล้ว · ชั่วโมงเดือนนี้ (รวม OT) · ค่าแรงเดือนนี้ · อัตราผ่าน QC 7 วันล่าสุด · ข้อบกพร่อง |
| ทะเบียนทีมและพนักงาน | ตำแหน่ง ค่าแรง รายชื่อพนักงาน รหัส สถานะ |
| มอบหมายเข้าโครงการ | เลือกโครงการ ทีม ช่วงเวลา ขอบเขต · ดูชั่วโมงสะสม ค่าแรงสะสม **ค่าแรงต่อบานที่ติดตั้ง** |
| ชั่วโมงทำงานและค่าแรง | บันทึกรายวันต่อโครงการ: ติ๊กชื่อพนักงาน ใส่ชั่วโมงปกติ / OT · สรุปรายคน รายโครงการ รายทีม · ส่งออก Excel |

💡 **ค่าแรงต่อบานที่ติดตั้ง** ช่วยเทียบว่าใช้ทีมภายในหรือจ้างผู้รับเหมาคุ้มกว่ากัน

🎨 **ข้อเสนอการจัดภาพ:** ภาพนาฬิกา × เหรียญ = ต้นทุน พร้อมตารางค่าแรง 4 ตำแหน่ง

## 18. ผู้รับเหมาภายนอก: สัญญาและงานเพิ่ม

🎯 **ข้อความหลัก:** "ทุกผู้รับเหมาต้องมีสัญญา เงื่อนไขเงินชัดเจนตั้งแต่ต้น"

### 18.1 ทะเบียนผู้รับเหมา
ชื่อ หัวหน้าทีม เลขประจำตัวผู้เสียภาษี จด VAT หรือไม่ ความชำนาญ

### 18.2 สัญญาว่าจ้าง (MOA) มีอะไรบ้าง

| หัวข้อ | ความหมายแบบง่าย |
|---|---|
| เลขที่สัญญา + ไฟล์ลงนาม | **บังคับ** ไม่มีสัญญา ไม่มีการจ่ายเงิน |
| มูลค่าสัญญา | ค่าจ้างรวมทั้งหมด |
| วิธีคิดค่าจ้าง | ต่อตารางเมตร (มีขั้นต่ำต่อบาน) หรือต่อบาน |
| ภาษีหัก ณ ที่จ่าย | % ที่หักทุกครั้งที่จ่าย |
| **เงินประกันผลงาน** | % ที่บริษัทหักเก็บไว้ คืนเมื่อพ้นระยะประกัน |
| **ระยะเวลาประกันผลงาน** | จำนวนเดือนที่ผู้รับเหมาต้องรับผิดชอบงาน |
| **มัดจำ** | เงินที่จ่ายล่วงหน้า และวิธีหักคืน (ตามสัดส่วนทุกงวด หรือหักเต็มในงวดแรก) |
| **หักเงินงวดตรวจรับงาน** | % ที่หักไว้ทุกงวด จ่ายคืนเมื่อทุกบานผ่าน QC |
| งวดการจ่าย | เพิ่ม/ลดงวดได้ |

### 18.3 สัญญาเพิ่มเติม / งานเพิ่ม
- จ้างผู้รับเหมาเดิมทำงานเพิ่มในโครงการเดิม → ทำ **บันทึกข้อตกลงงานเพิ่ม (F-14)** แนบท้ายสัญญา
- มูลค่าสัญญารวมเพิ่มขึ้นอัตโนมัติ
- งานเพิ่มที่ตรวจรับแล้ว **นำไปส่งเบิกได้** เหมือนงานปกติ และนับเป็นต้นทุนจริง

### 18.4 อัตราค่าจ้างติดตั้ง
- ต่อตารางเมตร หรือต่อบานตามประเภท
- ระบบคำนวณค่าจ้างรวมจากการมอบงานรายบาน
- ปรับเฉพาะบานได้

🎨 **ข้อเสนอการจัดภาพ:** ภาพสัญญาที่มีป้ายชี้ 4 จุดเงิน (มัดจำ · หักงวดตรวจรับ · เงินประกัน · ระยะประกัน)

## 19. การส่งงานและเบิกเงินผู้รับเหมา

🎯 **ข้อความหลัก:** "ส่งงาน → ตรวจรับ → เบิก → อนุมัติ → จ่าย ทุกขั้นตรวจสอบได้"

### 19.1 ขั้นตอน 7 ขั้น

```
1 ผู้รับเหมาส่งงานพร้อมรูป
→ 2 บริษัทตรวจรับรายจุด
→ 3 ผู้รับเหมาเลือกงานที่ตรวจรับแล้ว ทำ "ใบส่งเบิกงานงวด" (F-15)
→ 4 บริษัทอนุมัติ หรือตีกลับ
→ 5 ผู้รับเหมาออกใบแจ้งหนี้ (F-16)
→ 6 บัญชีบันทึกจ่ายเงิน
→ 7 ระบบบันทึกเป็นต้นทุนค่าแรงอัตโนมัติ
```

### 19.2 สถานะของใบเบิก
`ส่งเบิก` → `อนุมัติเบิก` → `ออกใบแจ้งหนี้` → `จ่ายแล้ว`

### 19.3 จุดเด่น
- ⭐ **ใบเดียวจบ:** ใบส่งเบิกงานงวดแสดงเลขงวด รายการงาน ยอดสะสม และช่องลงนามอนุมัติ
- ⭐ **กันเบิกซ้ำ:** งานที่ส่งเบิกแล้วจะไม่ถูกนับซ้ำในงวดอื่น
- ⭐ ถ้าตีกลับหรือยกเลิก รายการกลับมาให้ส่งเบิกใหม่ได้
- ⭐ **เงินงวดตรวจรับงาน** ที่หักไว้ ส่งเบิกคืนได้เมื่อทุกบานของทีมผ่าน QC
- ⭐ หน้า "ค่าจ้างตามผลงาน" ดูทุกงานที่ตรวจรับแล้วตามช่วงเวลา จ่ายแล้ว / ค้างจ่าย ส่งออก Excel ได้
- ⭐ แยกคนส่งเบิก คนอนุมัติ คนจ่าย ตามสิทธิ์ (ป้องกันคนเดียวทำครบทุกขั้น)

🎨 **ข้อเสนอการจัดภาพ:** ลูกศร 7 ขั้น ใช้สีแยกผู้ทำ (ผู้รับเหมา = ส้ม · บริษัทตรวจ = น้ำเงิน · บัญชี = เขียว)

## 20. การคำนวณเงินที่จ่ายผู้รับเหมาแต่ละงวด

🎯 **ข้อความหลัก:** "ระบบหักมัดจำ หักงวด หักภาษี หักเงินประกัน ให้อัตโนมัติ"

### 20.1 ลำดับการคำนวณ

| ลำดับ | รายการ | วิธีคิด |
|---|---|---|
| 1 | **มูลค่างานงวดนี้** | รวมค่าจ้างของงานที่ตรวจรับแล้วที่เลือก (รวมงานเพิ่ม) |
| 2 | − หักคืนเงินมัดจำ | ตามสัดส่วน หรือหักเต็มจนครบ (ไม่เกินมัดจำที่เหลือ) |
| 3 | − หักเงินงวดตรวจรับงาน | มูลค่างาน × % ที่กำหนด |
| 4 | = **ฐานวางบิล** | 1 − 2 − 3 |
| 5 | + VAT 7% | คิดจากฐานวางบิล (เฉพาะผู้รับเหมาที่จด VAT) |
| 6 | − ภาษีหัก ณ ที่จ่าย | คิดจากฐานวางบิล |
| 7 | − เงินประกันผลงาน | คิดจากมูลค่างานเต็ม (ข้อ 1) |
| 8 | = **ยอดจ่ายสุทธิ** | ฐานวางบิล + VAT − ภาษีหัก ณ ที่จ่าย − เงินประกันผลงาน |

### 20.2 ตัวอย่างประกอบ (ตัวเลขสมมติ เพื่อการอธิบายเท่านั้น)

สมมติ: งานงวดนี้ 100,000 บาท · มัดจำหักตามสัดส่วน 10% · หักงวดตรวจรับ 10% · ผู้รับเหมาจด VAT · หัก ณ ที่จ่าย 3% · เงินประกันผลงาน 5%

| รายการ | บาท |
|---|---:|
| มูลค่างานงวดนี้ | 100,000 |
| หักคืนมัดจำ (10%) | −10,000 |
| หักงวดตรวจรับ (10%) | −10,000 |
| **ฐานวางบิล** | **80,000** |
| VAT 7% | +5,600 |
| หัก ณ ที่จ่าย 3% (ของฐาน) | −2,400 |
| เงินประกันผลงาน 5% (ของงานเต็ม) | −5,000 |
| **ยอดจ่ายสุทธิ** | **78,200** |

> หมายเหตุ: % ทั้งหมดเป็นตัวอย่าง ค่าจริงตามที่กำหนดในสัญญาของผู้รับเหมาแต่ละราย

🎨 **ข้อเสนอการจัดภาพ:** แผนภูมิน้ำตก (waterfall) เริ่มที่ 100,000 ลดลงทีละขั้นจนเหลือยอดจ่ายสุทธิ

## 21. หนังสือรับรองเงินประกันผลงาน

🎯 **ข้อความหลัก:** "ออกหนังสือรับรองได้เมื่องานผ่านครบเท่านั้น"

- **ออกได้เมื่อ:** ทุกบานของทีมผ่าน QC (S6) และงานเพิ่มตรวจรับครบ
- **วันที่ออกหนังสือ ต้องไม่ก่อนวันตรวจรับงานทั้งหมด** ระบบไม่ยอมให้ลงวันที่ย้อน
- **ในหนังสือแสดง:**
  - ทุกครั้งที่จ่ายเงินและหักเงินประกัน: **วันที่จ่าย เลขที่อ้างอิง ยอดเงินที่หัก**
  - ยอดเงินประกันรวม
  - ระยะเวลาประกันผลงาน และ **วันที่ครบกำหนดคืนเงิน**
- พิมพ์เป็นแบบฟอร์ม F-17

💡 ผู้รับเหมาได้หลักฐานยอดเงินประกันที่ถูกต้อง บริษัทมีหลักฐานว่าคืนเงินตามเงื่อนไข

🎨 **ข้อเสนอการจัดภาพ:** ภาพเอกสารพร้อมตราประทับ และไทม์ไลน์ "ตรวจรับครบ → ออกหนังสือ → พ้นประกัน → คืนเงิน"

# ส่วนที่ 5 · การเงิน

## 22. ต้นทุนโครงการ

🎯 **ข้อความหลัก:** "รู้ต้นทุนจริงทุกวัน ไม่ต้องรอปิดโครงการ"

### 22.1 ต้นทุน 3 หมวด

| หมวด | มาจากไหน |
|---|---|
| **ค่าสินค้า** | เลือกได้ 2 แบบ: ① **ดึงจากรายการขาย (SO)** ต้นทุนเป็น % ของราคาขายหรือกำหนดรายบรรทัด รับรู้เมื่อของถึงหน้างาน (S4) ② **บันทึกเอง / นำเข้า Excel** |
| **ค่าแรงช่าง** | ผู้รับเหมา = ค่าจ้างตามงานที่ตรวจรับแล้ว (รวมงานเพิ่ม) · ทีมภายใน = ชั่วโมงทำงาน × ค่าแรง · ค่าแรงรายวันอื่น ๆ ที่บันทึก |
| **ค่าใช้จ่ายอื่น** | ค่าขนส่ง นั่งร้าน ที่พัก ฯลฯ ที่บันทึก |

### 22.2 งบประมาณเทียบใช้จริง
- แสดงงบ ใช้ไป คงเหลือ และ % ที่ใช้ไปของแต่ละหมวด
- ⚠️ **เตือนเมื่อค่าแรงเดินเร็วกว่างานที่ผ่าน QC** (เช่น ใช้ค่าแรงไป 60% แต่งานผ่าน QC แค่ 40%)

💡 **"ต้นทุนจริงถึงวันนี้"** คิดจากงานที่ตรวจรับแล้วจริง ไม่ใช่ตัวเลขประมาณ

🎨 **ข้อเสนอการจัดภาพ:** หลอดงบประมาณ 3 หลอด (สินค้า / ค่าแรง / อื่น ๆ) เติมสีตาม % ที่ใช้ และป้ายเตือนสีส้ม

## 23. การรับรู้รายได้ตามความสำเร็จของงาน (POC)

🎯 **ข้อความหลัก:** "รับรู้รายได้ตามงานที่ทำได้จริง ตรงตามหลักบัญชี"

**POC คืออะไร (แบบง่าย):** งานติดตั้งใช้เวลาหลายเดือน บัญชีจึงต้องทยอยบันทึกรายได้ตามสัดส่วนงานที่ทำเสร็จ เช่น งานเสร็จ 30% ก็รับรู้รายได้ 30% ของมูลค่าสัญญา

### 23.1 วิธีวัดความสำเร็จ (เลือกได้ 2 แบบ)
1. **ตามปริมาณงานติดตั้งที่ตรวจรับแล้ว** (ถ่วงตามมูลค่าของแต่ละบาน)
2. **ตามต้นทุนที่เกิดขึ้นจริงเทียบงบประมาณ**

### 23.2 สิ่งที่ระบบแสดง
- เลือกช่วงเวลาและโครงการ
- **% ความสำเร็จ** ต้นช่วง → ปลายช่วง
- รายได้ที่รับรู้ **ในช่วงนี้ / สะสม / คงเหลือ**
- ปริมาณงานติดตั้ง
- ค่าจ้างช่างที่เกิดขึ้นเทียบกับที่จ่ายแล้ว
- แยกรายเดือนหรือรายสัปดาห์

💡 ฝ่ายบัญชีได้ตัวเลขปิดงบจากข้อมูลหน้างานจริง ไม่ต้องขอตัวเลขจากผู้จัดการโครงการ

🎨 **ข้อเสนอการจัดภาพ:** วงกลมโดนัท % ความสำเร็จ คู่กับแท่งรายได้รายเดือน

---

## 24. วางบิลและรับเงินจากลูกค้า

🎯 **ข้อความหลัก:** "วางบิลจากงานที่ส่งมอบจริง ติดตามเงินเข้าได้ทุกบาท"

### 24.1 วิธีวางบิล 3 แบบ
1. **ตามบานที่ส่งมอบแล้ว** (S7)
2. **ตาม % ของสัญญา**
3. **กำหนดเอง**

### 24.2 การคำนวณ
- VAT 7% คิดเฉพาะค่าสินค้าและค่าติดตั้ง · **ค่าขนส่งไม่มี VAT**
- หักเงินประกันผลงานและภาษีหัก ณ ที่จ่าย (ตามที่ลูกค้าหัก)

### 24.3 สถานะ
```
ร่าง → ส่งให้ลูกค้า → รับเงินบางส่วน → รับเงินครบ
                    ↘ ยกเลิก
```
- รับเงินได้หลายครั้งต่อหนึ่งใบแจ้งหนี้
- พิมพ์ใบแจ้งหนี้ลูกค้า (F-18)
- ⚠️ เตือนใบแจ้งหนี้ที่ **เกินกำหนดชำระ**

🎨 **ข้อเสนอการจัดภาพ:** ไทม์ไลน์ใบแจ้งหนี้ 4 จุด พร้อมไอคอนเงินเข้า

---

## 25. กระแสเงินสด

🎯 **ข้อความหลัก:** "รู้ล่วงหน้า 90 วัน ว่าเงินจะเข้าและออกเท่าไร"

### 25.1 หน้าภาพรวม
- 💚 **เงินรับ** จากลูกค้า
- ❤️ **เงินจ่าย** แยก ค่าสินค้า · ค่าแรง · ค่าใช้จ่ายอื่น
- **สุทธิ** (รับ − จ่าย)
- **ค้างรับ** จากลูกค้า และส่วนที่ **เกินกำหนด**
- **ค้างจ่าย** ผู้รับเหมา
- กราฟรายเดือน / รายสัปดาห์ พร้อมเส้นยอดสะสม
- **คาดการณ์ 90 วันข้างหน้า** จากใบแจ้งหนี้ที่ค้างรับและใบเบิกที่ค้างจ่าย

### 25.2 แท็บย่อย 4 แท็บ
| แท็บ | ใช้ทำอะไร |
|---|---|
| ภาพรวม | ตัวเลขสรุปและกราฟ |
| รายการรับ-จ่าย | ทุกรายการพร้อมยอดคงเหลือสะสม ส่งออก Excel |
| วางบิล / รับเงิน | ออกใบแจ้งหนี้ลูกค้าและบันทึกรับเงิน |
| จ่ายผู้รับเหมา | ใบเบิกทุกสถานะ บันทึกจ่าย |

🎨 **ข้อเสนอการจัดภาพ:** กราฟแท่งเงินเข้า (เขียว) / เงินออก (แดง) รายเดือน และเส้นยอดสะสม ส่วน 90 วันข้างหน้าเป็นเส้นประ

## 26. ภาพรวมทุกโครงการสำหรับผู้บริหาร

🎯 **ข้อความหลัก:** "หน้าเดียว เห็นทุกโครงการ รู้ว่าต้องสนใจโครงการไหน"

**สิ่งที่เห็นในหน้าเดียว**
- จำนวนโครงการ และสถานะของแต่ละโครงการ
- **ความคืบหน้า** จริงเทียบแผน
- **ความเสี่ยง:** งานล่าช้า ข้อบกพร่องค้าง ปัญหาหน้างานเปิดอยู่
- **กำหนดส่งมอบ** ที่ใกล้ถึง
- **ตัวเลขการเงิน:** มูลค่าสัญญา วางบิลแล้ว รับเงินแล้ว ต้นทุนเทียบงบ
- กดเข้าไปดูรายละเอียดของแต่ละโครงการได้ทันที
- แผนงานรวมทุกโครงการ (Gantt)

🎨 **ข้อเสนอการจัดภาพ:** ภาพหน้าจอจำลองแบบ "แผงหน้าปัด" มีการ์ดโครงการพร้อมไฟสถานะ

## 28. ผู้ใช้งานและการกำหนดสิทธิ์

🎯 **ข้อความหลัก:** "แต่ละคนเห็นและทำได้เท่าที่หน้าที่ต้องใช้"

### 28.1 ผู้ใช้ 2 ประเภท

| | 🏢 ผู้ใช้ภายใน | 🌐 ผู้ใช้ภายนอก |
|---|---|---|
| คือใคร | พนักงานบริษัท | ผู้รับเหมา ลูกค้า ผู้ควบคุมงาน ที่ปรึกษา |
| ต้องระบุ | บทบาท | **ชื่อบริษัท** + บทบาทภายนอก |
| โครงการที่เข้าถึง | ทุกโครงการ หรือเฉพาะบางโครงการ | **ต้องกำหนดเฉพาะโครงการ** |
| ข้อจำกัดพิเศษ | – | **ระบบปิดสิทธิ์การเงิน ต้นทุน การอนุมัติ การเสนองาน และการจัดการผู้ใช้เสมอ** แม้มีคนเผลอให้สิทธิ์ |

### 28.2 กำหนดสิทธิ์ได้ 3 ระดับ
1. **ระดับบทบาท:** ตารางสิทธิ์ × บทบาท ติ๊กเปิด/ปิดได้ · สร้างบทบาทใหม่โดยคัดลอกจากบทบาทเดิม
2. **ระดับบุคคล:** ปรับเฉพาะคน ทีละสิทธิ์ เป็น "ตามบทบาท / อนุญาตเพิ่ม / ไม่อนุญาต"
3. **ระดับโครงการ:** ทุกโครงการ หรือเฉพาะโครงการ · ผู้รับเหมาผูกกับทีมของตนเอง

### 28.3 สิทธิ์ 37 รายการ ใน 7 กลุ่ม
1. การขาย / เสนองาน
2. ภาพรวมและโครงการ
3. ขั้นตอนหน้างาน
4. ทีมช่างและการเบิกจ่าย
5. รายงานหน้างาน
6. การเงินและบัญชี
7. ระบบ

### 28.4 บทบาทตั้งต้น 10 บทบาท

| บทบาท | ประเภท | ทำอะไรได้หลัก ๆ |
|---|---|---|
| ผู้ดูแลระบบ | ภายใน | ทุกอย่าง + จัดการผู้ใช้ (ต้องมีอย่างน้อย 1 คนเสมอ) |
| ผู้บริหาร | ภายใน | เห็นการเงิน · อนุมัติเบิก ส่งมอบ ปิดโครงการ · บันทึกผลเสนองาน |
| ผู้จัดการโครงการ | ภายใน | บริหารโครงการ ทุกขั้นหน้างาน · อนุมัติเบิกช่าง · ทีมช่าง · รายงาน |
| วิศวกร / QC | ภายใน | สำรวจ อนุมัติแบบ ตรวจรับรายจุด ตรวจคุณภาพ ข้อบกพร่อง |
| โฟร์แมน | ภายใน | รับของ ส่งงาน ตรวจรับรายจุด รายงานประจำวัน ชั่วโมงทำงาน |
| ฝ่ายขาย / ประมาณราคา | ภายใน | ระบบเสนองาน ใบเสนอราคา เปิดโครงการ |
| บัญชี / การเงิน | ภายใน | รายการขาย ต้นทุน วางบิล รับเงิน จ่ายช่าง มุมบัญชี กระแสเงินสด |
| ผู้รับเหมา (ทีมช่าง) | ภายนอก | รับของ ส่งงาน ส่งเบิกงานงวดของทีมตนเอง |
| ลูกค้า / ผู้ควบคุมงาน | ภายนอก | ดูความคืบหน้าและแผนงาน เฉพาะโครงการของตน |
| ดูอย่างเดียว | ภายใน | ดูภาพรวมและรายโครงการ |

### 28.5 เครื่องมือเสริม
- ผู้ดูแลระบบกด **"ดูในฐานะ"** เพื่อทดลองว่าผู้ใช้แต่ละคนเห็นอะไรและทำอะไรได้
- ทุกจุดบันทึกสำคัญ **ตรวจสิทธิ์ก่อน** และแจ้งชื่อสิทธิ์ที่ขาด ถ้าไม่มีสิทธิ์

🎨 **ข้อเสนอการจัดภาพ:** วงกลมซ้อน 3 ชั้น (บทบาท → บุคคล → โครงการ) และไอคอนคน 10 แบบ แยกภายใน (น้ำเงิน) / ภายนอก (ส้ม)

| 10 | ค่าแรงบานปลาย | เตือนเมื่อค่าแรงเกินสัดส่วนงานที่ผ่าน QC · ดูค่าแรงต่อบานของทีมภายใน |

**มุมมองการกำกับดูแล (Governance)**
- **แบ่งแยกหน้าที่:** คนส่งเบิก ≠ คนอนุมัติ ≠ คนจ่าย

- **กฎบังคับในระบบ:** ข้ามขั้นไม่ได้ ไม่ต้องพึ่งความจำของคน
- **ตรวจสอบย้อนหลังได้:** เอกสารเลขที่เรียงเป็นระบบ พิมพ์ซ้ำได้

🎨 **ข้อเสนอการจัดภาพ:** ภาพโล่ป้องกัน มีความเสี่ยงเป็นลูกศรพุ่งเข้าหาและถูกกันไว้ หรือตาราง 2 คอลัมน์ ความเสี่ยง (แดง) → การควบคุม (เขียว)

## 31. ประโยชน์ต่อบริษัท แยกตามกลุ่มผู้ใช้

| 🏗️ **ผู้จัดการโครงการ** | รู้สถานะทุกบาน · แผนเทียบงานจริงอัตโนมัติ · หลักฐานขอขยายเวลา · ควบคุมค่าแรงเทียบงบ |
| 🔍 **วิศวกร / QC** | เช็กลิสต์ตรวจชัดเจน · ข้อบกพร่องมีเจ้าของและกำหนดแก้ · สถิติคุณภาพ |
| 👷 **โฟร์แมน / ทีมช่าง** | ใช้มือถือสแกนและถ่ายรูปส่งงาน · รู้ว่างานไหนผ่าน งานไหนต้องแก้ · บันทึกชั่วโมงง่าย |
| 🧾 **ผู้รับเหมา** | ส่งเบิกได้เองจากงานที่ผ่าน · เห็นยอดสะสม ยอดหัก ยอดจ่ายชัดเจน · ได้หนังสือรับรองเงินประกัน |
| 💵 **บัญชี / การเงิน** | ต้นทุนและรายได้ตามความคืบหน้าจากข้อมูลจริง · หักมัดจำ VAT ภาษี เงินประกันอัตโนมัติ · ติดตามค้างรับค้างจ่าย |
| 🏢 **ลูกค้า** | ดูความคืบหน้าโครงการของตนเอง · ได้เอกสารส่งมอบและรับประกันครบ |
| 🛡️ **การกำกับดูแล / ตรวจสอบภายใน** | แบ่งแยกหน้าที่ · หลักฐานทุกขั้น · กฎบังคับในระบบ · เอกสารตรวจสอบย้อนหลังได้ |

🎨 **ข้อเสนอการจัดภาพ:** วงล้อรอบระบบ มีคน 9 กลุ่มรอบ ๆ แต่ละคนมีป้ายประโยชน์ 1–2 ข้อ

## 32. ข้อจำกัดปัจจุบันและแผนพัฒนาต่อ

🎯 **ข้อความหลัก:** "ต้นแบบพร้อมทดลองใช้ ขั้นต่อไปคือเชื่อมระบบหลักของบริษัท"

### 32.1 ข้อจำกัดของต้นแบบ
- ⚠️ **ระบบสิทธิ์ควบคุมที่หน้าจอ** การเข้าถึงไฟล์ยังขึ้นกับการแชร์ ก่อนใช้กับข้อมูลจริงในวงกว้าง ควรย้ายไปใช้ระบบที่ยืนยันตัวตนฝั่งเซิร์ฟเวอร์
- ⚠️ **ยังไม่เชื่อมกับ SAP โดยตรง** ใบเสนอราคาและรายการขายนำเข้าด้วยไฟล์
- ⚠️ **ค่าแรงทีมภายในยังไม่แสดงในกระแสเงินสด** (ถือว่าจ่ายผ่านเงินเดือน)
- ⚠️ วิธีคิดภาษีหัก ณ ที่จ่ายและ VAT ของผู้รับเหมา ควรให้ฝ่ายบัญชียืนยันว่าตรงนโยบายบริษัท
- ⚠️ ต้นทุนสินค้าแบบดึงจาก SO ใช้ % ของราคาขายเป็นค่าตั้งต้น ควรกำหนดต้นทุนจริงรายบรรทัด
- ⚠️ ข้อมูลในระบบปัจจุบันเป็นข้อมูลตัวอย่าง

### 32.2 แผนพัฒนาต่อ (ข้อเสนอ)
1. 🔗 **เชื่อม SAP** ดึงรายการขาย ราคาทุน สถานะผลิตและจัดส่งอัตโนมัติ
2. 🔔 **แจ้งเตือนผ่าน LINE / อีเมล** เมื่อถึงกำหนดติดตามลูกค้า ข้อบกพร่องใกล้ครบกำหนด หรือมีใบเบิกรออนุมัติ
3. 📧 **ส่งใบเสนอราคาและใบแจ้งหนี้** พร้อมไฟล์ PDF จากระบบโดยตรง
4. 👷 **ดึงจำนวนคนในรายงานประจำวัน** จากใบลงเวลาทีมภายใน
5. 📜 **บันทึกประวัติการแก้ไข (Audit log)** รายผู้ใช้ เพื่อการตรวจสอบภายใน
6. 🔐 **ระบบยืนยันตัวตนฝั่งเซิร์ฟเวอร์** ก่อนขยายผลทั้งบริษัท

🎨 **ข้อเสนอการจัดภาพ:** ถนนแผนงาน (roadmap) 3 ระยะ: ปัจจุบัน (ต้นแบบ) → ระยะถัดไป (เชื่อม SAP + แจ้งเตือน) → ระยะยาว (ใช้ทั้งบริษัท)

## 33. อภิธานศัพท์

### 34.2 ชุดย่อ (1 แผ่น สำหรับเปิดการประชุม)
1. **หัวเรื่อง:** "ติดตามงานติดตั้งทุกบาน ตั้งแต่ได้งานจนปิดโครงการ ในระบบเดียว"
2. **แถบบน:** เส้นทาง 8 สถานี (เสนองาน → … → ปิดงาน)
3. **กลาง ซ้าย:** กล่องตัวเลข 4 กล่อง (10 เมนู · 8 ขั้นตอน · 19 แบบฟอร์ม · 90 วันคาดการณ์เงินสด)
4. **กลาง ขวา:** หลักการ 3 ข้อ (ไม่มีหลักฐาน ไม่ผ่าน · ตรวจรับก่อนจ่าย · เห็นเท่าที่ควรเห็น)
5. **แถบล่าง:** ประโยชน์ 3 กลุ่ม (ผู้บริหาร · หน้างาน · บัญชี)

### 34.3 ข้อแนะนำด้านภาพ
- **สีตามช่วงงาน:** การขาย = ส้มอ่อน · เตรียมงาน/หน้างาน = น้ำเงิน · ส่งมอบ/ปิด = เขียว · การเงิน = เหลืองทอง
- **สีสถานะ:** เขียว = ผ่าน/ตามแผน · เหลือง = เฝ้าระวัง · แดง = ล่าช้า/ไม่ผ่าน
- **ภายใน vs ภายนอก:** น้ำเงิน vs ส้ม ใช้ให้เหมือนกันทุกแผ่น
- ใช้ **ไอคอนแทนคำ** ให้มากที่สุด และใส่ข้อความไม่เกิน 2 บรรทัดต่อกล่อง
- ทุกตัวเลขที่เป็นค่าตั้งต้นของระบบ ควรระบุว่า "ค่าตั้งต้น ปรับได้" เพื่อไม่ให้เข้าใจว่าเป็นผลการดำเนินงานจริง
